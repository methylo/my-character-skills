>
> 독자 단톡방 「AI 책쓰기: 집필의 기술」 — [카카오톡 오픈채팅 참여](https://open.kakao.com/o/ghqbvP0h)

내 사진으로 캐리커처 캐릭터를 만들고, 그 캐릭터로 4컷 웹툰까지 완성하는 ChatGPT 스킬입니다. 이미지 생성까지 ChatGPT 안에서 진행합니다.

## 어떤 걸 받을까

같은 내용을 두 가지 방식으로 제공합니다. **둘 중 하나만** 등록하면 됩니다.

| 방식 | 받을 파일 | 이런 경우에 |
|---|---|---|
| **통합본 (스킬 1개)** | `my-character-studio.zip` | 스킬 하나로 캐릭터부터 웹툰까지 이어서 만들고 싶을 때 |
| **파트별 (스킬 2개)** | `my-character.zip` + `my-character-webtoon.zip` | 수업에서 파트1·파트2를 나눠 진행하거나, 한쪽만 쓰고 싶을 때 |

| 스킬 | ChatGPT 표시 이름 | 하는 일 |
|---|---|---|
| `my-character-studio` | 내 캐릭터·웹툰 만들기 | 첨부한 자료를 보고 시작할 곳을 고릅니다. 사진이면 캐릭터 만들기, 완성 캐릭터면 4컷 웹툰 만들기, 사진부터 웹툰까지 요청하면 두 작업을 이어서 진행합니다. 작업을 정하지 않고 부르면 세 가지 작업을 안내하고, 진행 상태는 `캐릭터 만들기 1/4 · 콘셉트 선택`, `4컷 웹툰 만들기 1/6 · 이야기 선택`처럼 표시합니다. 파트별 스킬에 없는 기능도 있습니다(아래 참고). |
| `my-character` (파트1) | 내 캐릭터 만들기 | 내 사진의 닮은 특징을 살려 더 멋지고 코믹한 상반신 캐리커처 기본형을 만듭니다. |
| `my-character-webtoon` (파트2) | 내 캐릭터로 4컷 웹툰 만들기 | 완성한 캐릭터 기본형으로 이야기와 대사가 있는 4컷 웹툰을 만듭니다. |

### 통합본에만 있는 기능 (2026-11-20 갱신)

- **흑백/컬러와 그림체를 따로 선택**: 펜 선화·연필 스케치·펜 수채화·디지털 일러스트·굵은 선 웹툰 중에서 고르고, 시작할 때 정한 컬러가 유지됩니다.
- **같은 캐릭터의 포즈·그림체·실루엣 바꾸기**: 기본형의 얼굴과 그림체는 그대로 두고 새 포즈를 만듭니다. "멋있게", "슬림하게"처럼 요청한 부위와 정도만 조정합니다.
- **이야기와 등장인물을 함께 추천**: 웹툰 1단계에서 이야기 3안마다 추천 인물과 역할을 보여 주고, 한 번에 고르게 합니다.
- **여러 에피소드 추천**: 다음 편 후보를 기본 5편 추천하고, 먼저 만들기 좋은 편을 제안합니다.
- **컷마다 꼭 보여야 할 요소 지정**: 마지막 컷의 반전 단서는 위치·크기·여백까지 지정하고, 강의 슬라이드 크기에서 읽히는지 점검합니다.

아래 단계 표는 두 방식에 공통입니다. 통합본의 2단계에서는 표현 방향, 흑백/컬러, 그림체를 각각 고릅니다.

### 파트1 · 내 캐릭터 만들기 (4단계)

| 단계 | 하는 일 | 입력 예 |
|---|---|---|
| 1. 콘셉트 선택 | 사진 특징 분석, 콘셉트 A·B·C 추천 | `B형으로` |
| 2. 표현 방향·스타일 선택 | 닮음·멋스러움·코믹함과 그림체·색·구도 비교 | `멋스러움 중심, 표정은 코믹하게` |
| 3. 이미지 프롬프트 작성 | 선택을 반영한 복사용 프롬프트 | `이 프롬프트로 1장 생성해줘` |
| 4. 이미지 생성 | 제작, 결과 선택·수정, 기본형 확정 | `2번을 더 코믹하게 수정해줘` |

`키트로 줘`라고 하면 스킬 없이도 쓸 수 있는 복사용 프롬프트를 줍니다.

### 파트2 · 내 캐릭터로 4컷 웹툰 만들기 (6단계)

| 단계 | 하는 일 |
|---|---|
| 1. 이야기 선택 | 기본형 확인, 유지할 특징 정리, 이야기 3안 추천 |
| 2. 스타일·비율 선택 | 스타일 3종, 흑백/컬러, 전체 비율 추천 |
| 3. 장면·연출·대사 구성 | 등장인물 선택 후 네 장면·대사·재미 보강안 |
| 4. 이미지 프롬프트 2안 작성 | 균형형과 코믹 연출형 프롬프트 |
| 5. 웹툰 생성·수정 | 실제 제작과 부분 수정 |
| 6. 검수·최종 완성 | 이야기·외형·스타일·비율·한글 점검 |

## ChatGPT에 등록하기

**통합본**: [my-character-studio.zip](./downloads/my-character-studio.zip?raw=1)을 내려받아 ChatGPT의 스킬 등록 화면에서 올립니다.

**파트별**: 아래 두 파일을 내려받아 하나씩 올립니다.
- [my-character.zip](./downloads/my-character.zip?raw=1)
- [my-character-webtoon.zip](./downloads/my-character-webtoon.zip?raw=1)

등록 화면의 위치와 명칭은 ChatGPT 버전과 요금제에 따라 다를 수 있습니다. 이미지 생성을 쓰므로 이미지 생성이 가능한 ChatGPT 환경이 필요합니다.

## 사용 방법

### 통합본

```
my-character-studio 스킬로 첨부한 내 사진으로 캐릭터를 만들어줘. 콘셉트 3안부터 보여줘.
```

```
my-character-studio 스킬로 첨부한 완성 캐릭터로 4컷 웹툰을 만들어줘. 주제와 이야기 3안부터 추천해줘.
```

```
my-character-studio 스킬로 첨부한 내 사진에서 캐릭터를 만들고, 기본형을 확정한 뒤 4컷 웹툰까지 이어서 진행해줘.
```

```
my-character-studio 스킬로 첨부한 사진의 캐릭터를 만들어줘.
색상은 컬러, 그림체는 펜 선화로 정하고, 콘셉트 3안을 먼저 추천해줘.
```

```
my-character-studio 스킬로 기본형의 얼굴과 그림체를 유지해줘.
두 번째 첨부 사진에서는 자세만 참고하고, 같은 캐릭터의 새 포즈로 1장 생성해줘.
```

```
my-character-studio 스킬로 이 캐릭터의 다음 4컷 웹툰 에피소드를 5편 추천해줘.
주제는 추천해주고 제목, 시작 상황, 마지막 컷의 반전, 추천 인물을 보여줘.
```

### 파트별

**파트1** — 내 사진을 첨부하고:

```
$my-character 스킬로 첨부한 내 사진의 캐리커처를 만들어줘. 먼저 1단계에서 콘셉트 3안을 추천하고 내 선택을 기다려줘.
```

**파트2** — 파트1에서 확정한 캐릭터 기본형 이미지를 첨부하고:

```
$my-character-webtoon 스킬로 첨부한 캐릭터의 4컷 웹툰을 만들어줘. 먼저 1단계에서 이야기 3안을 추천하고 내 선택을 기다려줘.
```

각 단계에서 선택을 받은 뒤 다음 단계로 넘어갑니다. 진행 중에는 매 답변에 현재 단계, 설정, 다음 행동을 보여 줍니다.

## 주의

- 본인 사진으로 진행합니다. 다른 사람의 사진은 그 사람의 동의를 받은 경우에만 씁니다.
- 체형·피부색·나이·탈모·흉터는 과장하지 않도록 스킬에 정해 두었습니다.
- 이 스킬은 ChatGPT의 이미지 생성 도구에 맞춰 작성되어 있습니다. 다른 서비스에서는 그대로 동작하지 않을 수 있습니다.
- 통합본과 파트별 스킬을 함께 등록하면 같은 요청에 어느 스킬이 불릴지 헷갈릴 수 있습니다. 한 방식만 등록하세요.
