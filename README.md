# 내 캐릭터 만들기 (my-character-skills)

내 사진으로 캐리커처 캐릭터를 만들고, 그 캐릭터로 4컷 웹툰까지 완성하는 ChatGPT 스킬 두 개입니다. 파트1에서 만든 캐릭터 기본형을 파트2에 첨부해 이어서 씁니다.

## 두 스킬

| 순서 | 스킬 | ChatGPT 표시 이름 | 하는 일 |
|---|---|---|---|
| 파트1 | `my-character` | 내 캐릭터 만들기 | 내 사진의 닮은 특징을 살려 더 멋지고 코믹한 상반신 캐리커처 기본형을 만듭니다. |
| 파트2 | `my-character-webtoon` | 내 캐릭터로 4컷 웹툰 만들기 | 완성한 캐릭터 기본형으로 이야기와 대사가 있는 4컷 웹툰을 만듭니다. |

### 파트1 · 내 캐릭터 만들기 (4단계)

| 단계 | 하는 일 | 입력 예 |
|---|---|---|
| 1. 콘셉트 선택 | 사진 특징 분석, 콘셉트 A·B·C 추천 | `B형으로` |
| 2. 표현 방향·스타일 선택 | 닮음·멋스러움·코믹함과 그림체·색·구도 비교 | `멋스러움 중심, 표정은 코믹하게` |
| 3. 이미지 프롬프트 작성 | 선택을 반영한 복사용 프롬프트 | `이 프롬프트로 1장 생성해줘` |
| 4. 이미지 생성 | 제작, 결과 선택·수정, 기본형 확정 | `2번을 더 코믹하게 수정해줘` |

`키트로 줘`라고 하면 스킬 없이도 쓸 수 있는 복사용 프롬프트를 줍니다.

### 파트2 · 내 캐릭터로 4컷 웹툰 만들기 (6단계)

| 단계 | 하는 일 |
|---|---|
| 1. 이야기 선택 | 기본형 확인, 유지할 특징 정리, 이야기 3안 추천 |
| 2. 스타일·비율 선택 | 스타일 3종, 흑백/컬러, 전체 비율 추천 |
| 3. 장면·연출·대사 구성 | 등장인물 선택 후 네 장면·대사·재미 보강안 |
| 4. 이미지 프롬프트 2안 작성 | 균형형과 코믹 연출형 프롬프트 |
| 5. 웹툰 생성·수정 | 실제 제작과 부분 수정 |
| 6. 검수·최종 완성 | 이야기·외형·스타일·비율·한글 점검 |

## ChatGPT에 등록하기

1. 아래 zip 두 개를 내려받습니다.
   - [my-character.zip](./downloads/my-character.zip?raw=1)
   - [my-character-webtoon.zip](./downloads/my-character-webtoon.zip?raw=1)
2. ChatGPT의 스킬 등록 화면에서 두 파일을 하나씩 올립니다.

등록 화면의 위치와 명칭은 ChatGPT 버전과 요금제에 따라 다를 수 있습니다. 이미지 생성을 쓰므로 이미지 생성이 가능한 ChatGPT 환경이 필요합니다.

## 사용 방법

**파트1** — 내 사진을 첨부하고:

```
$my-character 스킬로 첨부한 내 사진의 캐리커처를 만들어줘. 먼저 1단계에서 콘셉트 3안을 추천하고 내 선택을 기다려줘.
```

**파트2** — 파트1에서 확정한 캐릭터 기본형 이미지를 첨부하고:

```
$my-character-webtoon 스킬로 첨부한 캐릭터의 4컷 웹툰을 만들어줘. 먼저 1단계에서 이야기 3안을 추천하고 내 선택을 기다려줘.
```

각 단계에서 선택을 받은 뒤 다음 단계로 넘어갑니다. 진행 중에는 매 답변에 현재 단계, 설정, 다음 행동을 보여 줍니다.

## 주의

- 본인 사진으로 진행합니다. 다른 사람의 사진은 그 사람의 동의를 받은 경우에만 씁니다.
- 체형·피부색·나이·탈모·흉터는 과장하지 않도록 스킬에 정해 두었습니다.
- 이 스킬은 ChatGPT의 이미지 생성 도구에 맞춰 작성되어 있습니다. 다른 서비스에서는 그대로 동작하지 않을 수 있습니다.
