# 주제 추천 자료

이 표는 초보자가 짧은 소재만으로 시작하도록 돕는 창작 소재 은행이다. 실제 경험·인기·통계 데이터로 소개하지 않는다. 현재 캐릭터와 사용자 용도에 맞게 변형하며 불필요한 직업·성격 추정을 하지 않는다.

## 입력 예시와 이야기 씨앗

| 범주 | 짧게 입력할 주제 | 4컷으로 펼칠 상황 | 연출 메모 |
| --- | --- | --- | --- |
| 일상 | 커피 한 잔 | 마시려는 순간 방해받고 뒤늦게 맛을 봄 | 컵·손·표정, 상반신 가능 |
| 일상 | 간식 하나만 | 하나만 먹으려다 빈 봉지를 발견 | 봉지·입꼬리·손짓 |
| 일상 | 찾던 물건 | 책상에서 찾다가 손에 쥔 것을 발견 | 새 소품으로 설정, 고정 액세서리를 임의 제거하지 않기 |
| 일상 | 아침 준비 | 서두르다 물건 하나를 빠뜨려 다시 확인 | 상반신이면 책상·가방 중심 |
| 디지털 | 스마트폰 알림 | 잠깐 확인하려다가 하려던 일을 잊음 | 화면 글자보다 표정과 반복 동작 |
| 디지털 | 배터리 1퍼센트 | 중요한 순간 충전기를 찾음 | 숫자 대신 충전선·걱정 표정으로 전달 |
| 디지털 | 사진 한 장 | 한 장만 찍으려다 포즈를 계속 바꿈 | 다른 인물 추가 없이 타이머 촬영 |
| 디지털 | 정리할 파일 | 정리하려다 폴더만 더 늘어남 | 화면 문구 의존도가 높으면 물리적 서류로 대체 |
| 일·공부 | 마감 전날 | 여유를 부리다가 시간에 놀라 집중 | 시계 숫자 없이 자세·책상 변화 |
| 일·공부 | 한 줄 쓰기 | 빈 종이를 보다가 작은 문장으로 시작 | 무대사에 읽을 수 있는 문구는 넣지 않기 |
| 일·공부 | 발표 직전 | 긴장해서 준비하다 첫 설명을 시작 | 사용자가 밝힌 발표 용도에만 연결 |
| 일·공부 | 할 일 목록 | 목록을 늘리다 하나를 먼저 끝내기로 함 | 글자보다 빈 칸·체크 형태, 명확한 시각화 필요 |
| 취미 | 책 한 장 | 집중하려다 졸다가 다시 읽음 | 책·눈꺼풀·고개 동작 |
| 취미 | 그림 그리기 | 작은 낙서가 뜻밖의 모양이 됨 | 그림 속 그림이 복잡해지지 않도록 단순화 |
| 취미 | 요리 첫 도전 | 기대하며 만들고 예상 밖 결과를 마주함 | 위험 행동 없이 완성 요리와 반응 중심 |
| 휴식 | 잠깐 쉬기 | 계속 방해받다 알림을 끄고 편안해짐 | 스마트폰·기지개·미소 |
| 휴식 | 창밖 보기 | 바쁘게 움직이다 창밖을 보고 속도를 늦춤 | 주인공의 시선과 자세 변화 |
| 휴식 | 책상 정리 | 물건을 쌓아두다 필요한 것만 남김 | 같은 물건의 위치와 개수 연속성 |

## 주제 입력에 따른 추천 방식

- 구체적 상황: ‘커피를 마시려는데 전화가 온다’ → 그 상황 안에서 공감·반전·작은 변화의 세 결말.
- 짧은 소재: ‘커피’ → 쉬는 순간·전화 방해·빈 잔 발견처럼 커피를 중심으로 세 이야기.
- 넓은 범주: ‘일상’ → 커피·간식·스마트폰 등 서로 다른 구체 소재 세 개.
- 미입력: 캐릭터에 무리 없는 범주에서 다른 소재 세 개를 추천하고 소재별 이야기까지 한 번에 제공.
- 이미 선택한 이야기가 있는 상태의 미입력: 다시 추천하지 말고 선택한 이야기로 다음 단계를 진행.

## 추천 기준

선택한 등장인물 구성(대화가 효과적이면 주인공과 조연 1명), 한 컷당 중심 행동 하나, 단순한 소품, 표정과 행동으로 읽히는 결말을 우선한다. 상반신 캐릭터에게 걷기·달리기 등 전신이 필수인 주제를 기본 추천하지 않는다. 무대사로 이해하기 어려운 소재는 더 명확한 시각적 상황으로 바꾼다. 예시를 그대로 반복하기보다 현재 캐릭터와 선택한 분위기에 맞게 조정한다.
