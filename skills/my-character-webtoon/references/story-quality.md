# 4컷 재미·품질 기준

재미는 독자마다 다르다. 아래는 창작과 검토의 기준이며 반응을 보장하거나 측정한 데이터가 아니다. 반복 자체를 위한 재생성이나 점수 올리기 대신 관찰한 약점을 고친다.

## 1. 네 컷의 역할

| 컷 | 독자가 알아야 할 것 | 장면에서 보일 것 |
| --- | --- | --- |
| 1 | 주인공의 작은 욕구·약속 | 갖고 싶은 것·하려는 행동·짧은 다짐 |
| 2 | 잘될 것 같은 기대 | 진행된 행동·구체적인 준비·기대 표정 |
| 3 | 예상이 어긋나는 계기 | 방해·새 단서·자기모순의 시작 |
| 4 | 앞 장면이 다르게 보이는 결말 | 소품 상태·과장된 반응·반전과 짧은 한마디 |

커피가 식었다처럼 예상 가능한 결과도 독특한 표정·행동·대사 조합으로 살릴 수 있다. 모든 이야기를 엉뚱한 초현실 반전으로 만들지 않는다. 사용자가 따뜻한 감성·정보 전달을 원하면 미소나 이해를 주는 결말로 조정한다.

## 2. 선택할 재미 장치

하나의 이야기에 중심 장치 하나만 사용한다. 다른 세 안은 같은 소품만 바꾼 복제 이야기가 되지 않게 한다.

| 장치 | 원리 | 짧은 예시 |
| --- | --- | --- |
| 자기모순 | 말한 결심과 실제 행동의 차이 | ‘딱 하나’라고 다짐하고 빈 봉지를 털어봄 |
| 기대 뒤집기 | 준비의 목적과 결과가 바뀜 | 쉬려고 알림을 끄다 설정에 더 몰두함 |
| 반복 뒤 변화 | 같은 시도를 반복하다 마지막에 결과가 달라짐 | 표정을 연습하다 실제 순간 엉뚱한 표정 |
| 소품 재발견 | 처음부터 보였던 단서가 결말이 됨 | 찾던 펜이 계속 손에 있었음 |
| 반응의 과장 | 작은 사건에 비해 큰 반응을 보임 | 식은 커피에 엄숙한 작별 인사 |
| 역할 바꾸기 | 사용하던 도구에 오히려 자신이 맞춰짐 | 알림을 무시하려다 휴대전화 눈치를 봄 |
| 말과 그림의 차이 | 자신 있는 말과 소심한 동작이 어긋남 | ‘바로 시작’이라며 책상만 정리 |
| 처음으로 되돌아오기 | 마지막이 첫 장면을 새 의미로 반복 | 휴식 계획을 끝내고 다시 휴식 계획을 세움 |

정체성·신체 특징을 웃음의 표적으로 과장하지 않는다. 캐릭터의 선택과 상황에서 웃음이 나오게 한다. 대사는 표정·행동을 보태며 그림에 없는 복잡한 사실을 떠넘기지 않는다.

## 3. 이야기 제시 전 점검

- 한 문장으로 줄거리를 말할 수 있는가.
- 각 컷이 앞 컷과 다르고, 2컷의 기대가 4컷 결말과 연결되는가.
- 웃음 포인트를 한 줄로 설명할 수 있는가. 없다면 사건 기록에서 한 번 더 비튼다.
- 3컷에서 이미 결말을 다 알려주지 않는가.
- 그림에서 보일 복선·반전·표정이 있는가. 화면 글자나 긴 해설에만 의존하지 않는가.
- 주인공 수·신체 범위·소품 수가 기본형과 4컷 분량에 맞는가.

약한 항목을 내부적으로 보완한 뒤 세 안을 제시한다. 사용자에게 채점표를 강제로 보여 주거나 선택 전에 또 다른 평가 단계를 만들지 않는다.

## 4. 장면·대사 품질

대사는 컷당 한 문장을 기본으로 짧고 소리 내어 읽히게 쓴다. 마지막 대사는 앞말을 그대로 반복하는 설명보다 반응·능청·역설을 활용한다. 예: 단순 ‘식었네’ 대신 상황에 맞는 ‘커피도 퇴근했네’ 같은 표현을 검토한다. 특정 문구를 모든 작품에 반복하지 않는다. 어려운 말장난·긴 대사는 피한다.

말풍선을 가렸다고 손과 얼굴을 지우거나 소품 상태를 바꾸지 않는다. 16:9·9:16·1:1의 전체 비율에 맞춰 여백을 계획한다. 대사가 길면 글자를 지나치게 줄이기보다 표현을 짧게 고친다. 사용자가 준 문구는 임의로 변경하지 않고 수정 제안을 받는다.

## 5. 생성 전후 확인

생성 전: 선택한 이야기·스타일·색·비율·배열·네 동작·소품 상태·정확한 대사·말풍선 위치가 장면표와 프롬프트에서 같은지 확인한다. 새 스타일 선택과 원본 그림체 고정 명령의 충돌을 제거한다.

생성 후: 접근 가능한 경우 이미지 가로·세로를 읽어 요청 비율을 교차곱으로 확인한다. 예를 들어 16:9는 가로×9=세로×16일 때만 정확히 일치하며 근사값과 구분한다. 핵심 소품 바닥·손잡이·접촉 부분의 잘림도 확인한다. 실제 이미지에서 정확히 네 컷인지, 캐릭터 정체성이 이어지는지, 반전 소품과 표정이 살아 있는지, 글자를 읽을 수 있는지 확인한다. 시각 자료에 접근하지 않고 점검 완료라고 하지 않는다. 자동으로 반복 생성하지 않고 발견한 결함과 수정안을 제시해 명확한 제작 요청에 따라 수정한다.

## 6. 전체 흐름 점검 시나리오

- 주제 없는 상반신 흑백 캐리커처: 서로 다른 소재 3안, 스타일·비율 선택, 대사 포함, 보이지 않는 전신 설정 추가 없음.
- 주제 ‘간식 하나만’, 코믹형·16:9·흑백: 같은 이야기·스타일을 프롬프트와 최종 검수까지 유지하고 한 편만 생성.
- 컬러 동물 기본형, 기본형 유지형·9:16·무대사: 고정 색·의상 유지, 대사·말풍선·제목 없음, 전체 비율과 컷 배열 구분.
- 대사 포함 결과의 한 컷 수정: 다른 컷·배열·비율·선택 스타일·확정 대사 유지 요청, 전체 재확인, 미검증 한글과 비율은 미확인으로 구분.

지침 시험과 실제 이미지 생성 시험을 구분하여 보고한다. 실제 생성하지 않았다면 그림 품질이나 한글 정확성을 검증했다고 말하지 않는다.

## 7. 등장인물 연결 점검

- 3단계에서 추천 인물 구성·역할·재미 효과가 드러나고 단독도 선택 가능한가. 조연을 넣기 위해 결말을 복잡하게 만들지 않는가.
- 조연 이미지 없이도 제안 외형으로 진행하고 흑백에서 실루엣·의상으로 주인공과 구분하는가. 선택한 인물 수에 의인화 캐릭터도 포함하는가.
- 각 컷의 등장 인물·화자·시선·위치가 명확하고 조연의 반응이 전개나 결말에 기여하는가. 두 프롬프트의 인물 설정과 정확한 대사가 같은가.
- 단독 선택 시 조연을 추가하지 않는가. 진행 중 인물 추가 시 바뀌는 장면·대사를 먼저 제안하고 현재 결과를 임의 재생성하지 않는가.
- 시험 예: 커피 주제와 주인공 이미지 한 장으로 시작 / 3단계에서 동료 1명 선택·외형 추천 적용 / 흑백 16:9 / 장면표·두 프롬프트까지 동일한 인물과 화자 유지.
