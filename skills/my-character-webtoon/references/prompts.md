# 웹툰 프롬프트 템플릿

대괄호를 확정 값으로 채워 완전한 프롬프트를 제공한다. 대사 포함이 기본이며 무대사는 사용자가 선택했을 때만 사용한다. 위치명은 확정 배열에 맞춰 변경한다. 4단계에서는 아래 기본 골격을 각 안마다 완전히 채워 프롬프트 두 개를 출력한다.

## 대사 포함 4컷 생성 — 기본

```text
첨부한 이미지 1은 [캐릭터 이름]의 기본형이야.
[고정 외형 3~5개·신체 비율·정체성을 유지할 의상]을 네 컷에서 유지해줘.
웹툰 스타일은 [선택한 A·B·C 스타일의 실제 선·명암·표정·동작 특징], 색은 [흑백 또는 확정 팔레트]로 통일해줘.
[기본형 유지형이면 기존 선과 색 유지; 다른 스타일이면 기본형의 정체성만 유지하고 표현 방식은 선택값 적용]
[흑백 선택 시 커피·피부·빛·배경도 모두 중성 회색으로, 갈색·베이지·부분 강조색 없음; 컬러면 삭제]
[추가 참조 번호와 역할; 없으면 삭제]
전체 이미지의 가로:세로 비율은 [16:9 / 9:16 / 1:1 중 확정값]이야.
이 비율 안에 4컷 웹툰 한 장을 만들어줘.
배열은 [기본 2×2], 각 칸은 같은 크기이며 경계와 여백을 분명하게 해줘.
읽는 순서는 [확정 배열의 읽는 순서]야.
[간단한 장소]에서 [확정 등장인물 총수]명이 등장해.
등장인물: [주인공의 참조·고정 외형], [추가 인물이 있으면 이름·가상 관계·참조 또는 제안 외형].
[인물별 등장 컷·기본 좌우 위치·시선; 의인화하면 사물의 고정 형태·표정·말하는 컷].
지정한 인물만 등장시키고 서로의 외형이나 의상을 바꾸지 마.
[반복 소품]은 [형태·색·크기]를 유지하고 위치·상태는 장면에 맞춰 바꿔줘.

1컷 [실제 위치]: [동작·표정·소품 상태·구도]. [화자]의 대사: “[확정 문구]”.
2컷 [실제 위치]: [동작·표정·소품 상태·구도]. [화자]의 대사: “[확정 문구]”.
3컷 [실제 위치]: [동작·표정·소품 상태·구도]. [화자]의 대사: “[확정 문구]”.
4컷 [실제 위치]: [동작·표정·소품 상태·구도]. [화자]의 대사: “[확정 문구]”.

각 컷의 중심 동작 하나와 감정이 분명하게 보이게 해줘.
핵심 소품은 바닥·손잡이·손과의 접촉 부분까지 컷 안에 온전히 보이게 하고 아래쪽 테두리에도 여백을 남겨줘.
1컷의 [시각적 복선]이 4컷의 [반전·웃음 포인트]로 이어지게 해줘.
3컷에서 결말을 먼저 드러내거나 4컷의 반응을 생략하지 마.
대사는 문구 그대로 정확한 한글로 넣어줘.
말풍선 꼬리는 각 컷에서 지정한 화자를 정확히 가리켜줘.
말풍선은 얼굴·손·핵심 소품을 가리지 않는 [컷별 위치]에 배치해줘.
[제목을 선택했으면 문구와 칸 밖 위치; 아니면 제목 없음]
확정 대사 외 글자·숫자·효과음·장식은 넣지 마.
[누적 수정 사항; 없으면 삭제]
```

## 무대사 선택 시

위 기본 템플릿에서 컷별 대사와 말풍선·제목 문구를 모두 삭제한다. 장면·비율·배열·고정 특징은 유지하고 아래 문장을 넣는다. 대사 포함 템플릿에 혼용하지 않는다.

```text
이번 결과는 무대사 웹툰이야.
말풍선·대사·글자·제목·효과음·숫자는 모두 넣지 마.
```

## 부분 수정

```text
이미지 1은 수정할 최신 웹툰이고 이미지 2는 캐릭터 기본형이야.
[컷 번호·실제 위치]의 [문제 부분]만 [원하는 모습]으로 수정해줘.
[고정 특징]과 [반복 소품 조건]을 유지해줘.
다른 세 컷, 전체 [선택 비율], [선택 배열], [선택 스타일·색·명암]과 [유지할 확정 대사]는 그대로 유지해줘.
[대사 변경이라면 해당 컷의 새 정확한 문구]
명시한 수정 사항 외에 인물·소품·글자를 추가하지 마. 인물 추가 요청이면 3단계에서 확정한 추가 인물과 해당 컷·대사 변경을 반영하고 나머지는 유지해줘.
```

## 기존 무대사 원본에 대사 추가

```text
첨부한 무대사 웹툰의 전체 [비율]·[배열]·캐릭터·그림체·동작·소품·배경을 유지해줘.
1컷 [위치] / 화자 [인물 이름]: “[확정 대사]”
2컷 [위치] / 화자 [인물 이름]: “[확정 대사]”
3컷 [위치] / 화자 [인물 이름]: “[확정 대사]”
4컷 [위치] / 화자 [인물 이름]: “[확정 대사]”
문구를 글자 그대로 넣고 말풍선 꼬리는 각 컷에서 지정한 화자를 정확히 가리켜줘.
말풍선은 얼굴·손·소품을 가리지 않게 배치해줘.
[제목 문구와 위치 또는 제목 없음]
다른 글자·숫자·효과음·장식은 추가하지 마.
```

의도적으로 대사가 없는 컷은 해당 문구를 ‘이 컷에는 대사·말풍선 없음’이라는 지시문으로 바꾸고 그 지시 자체를 이미지에 쓰지 않는다. 최종 이미지에서 한글과 기존 그림의 변화 여부를 확인한다.


## 프롬프트 두 안의 연출 지시

두 안의 확정 대사·장면 의미·고정 특징·스타일·색·배열·비율은 같게 유지한다. 아래 문장만 따로 주지 말고, 각 안의 완전한 기본 프롬프트 안에 통합한다.

- 1안 균형·가독성형: 네 장면의 손동작과 소품 상태가 한눈에 보이도록 안정된 중간 거리 구도를 사용한다. 표정은 분명하되 과장은 절제하고 마지막 컷의 핵심 행동과 대사가 함께 읽히게 한다.
- 2안 코믹 연출 강조형: 같은 스타일 안에서 확정 장면표의 의미·중심 행동을 유지하며 필요한 컷만 거리·표정·손동작의 대비를 높인다. 발견 장면이 없는 이야기에 발견을 추가하지 않는다. 마지막 웃음이 두 인물의 반응·큰 소품·공간 대비에 있으면 이를 함께 보여 주는 중간·넓은 구도를 유지하고, 표정이 핵심일 때만 가까운 구도를 사용한다. 마지막 컷의 표정과 작은 사건 사이의 대비를 강조한다. 새 소품·대사·사건을 추가하거나 결말을 앞 컷으로 옮기지 않는다.

사용자가 비코믹 정서를 지정하면 2안은 해당 정서를 지킨 채 시선·거리·여백의 대비로 조정한다. 두 안 모두 무대사 또는 대사 포함 선택을 동일하게 적용한다.
