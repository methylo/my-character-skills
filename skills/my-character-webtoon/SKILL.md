# 내 캐릭터로 4컷 웹툰 만들기

호출명은 `my-character-webtoon`과 ‘내 캐릭터로 4컷 웹툰 만들기’로 통일한다. 이전 호출명 `character-webtoon`으로 요청해도 같은 6단계로 진행한다. `my-character`(내 캐릭터 만들기)에서 확정한 기본형 또는 사용자가 첨부한 캐릭터를 입력으로 사용한다. 앞 스킬의 사용·설치를 필수로 요구하지 않는다.

파트1에서 확정한 캐릭터 이미지를 받아 한 편의 4컷 이야기로 만든다. 캐릭터 구상을 처음부터 반복하지 않는다. 이야기를 선택한 뒤 기본형 유지형·코믹 웹툰형·감성 일러스트형 중 표현 스타일을 선택하고 전체 이미지 비율과 장면·대사를 설계한다. 기본 완성물은 짧은 대사와 말풍선이 포함된 4컷이며 무대사는 사용자가 선택할 때 제작한다.

## 6단계와 상태 안내

처음 시작하거나 진행 상황을 물으면 표를 보여 준다. 이후에는 현재 단계·설정·다음 행동을 짧게 표시한다.

| 단계 | 하는 일 | 산출물·선택 |
| --- | --- | --- |
| 1. 이야기 선택 | 기본형 확인, 유지할 특징 정리, 이야기 3안 추천 | 이야기 한 편 선택 |
| 2. 스타일·비율 선택 | 스타일 3종·흑백/컬러·전체 비율 추천 | 표현 방식 선택 |
| 3. 장면·연출·대사 구성 | 등장인물 추천·선택 후 네 장면·대사·재미 보강안 | 인물 구성·장면·대사 확인·수정 |
| 4. 이미지 프롬프트 2안 작성 | 같은 설정의 균형형과 코믹 연출형 프롬프트 제공 | 프롬프트 번호·제작 장수 선택 |
| 5. 웹툰 생성·수정 | 선택한 프롬프트로 실제 제작·부분 수정 | 이미지 결과·수정 |
| 6. 검수·최종 완성 | 이야기·외형·스타일·비율·한글 점검 | 최종 완성본 |

상태 표시 예:
현재: 2/6단계 — 스타일·비율 선택
설정: [캐릭터 이름] / [이야기 제목] / [선택 스타일·흑백/컬러] / 전체 비율 [선택값 또는 미정] / 배열 [선택값] / 대사 포함 [또는 사용자 선택 무대사]
반영 사항: [수정 누적 또는 없음]
다음: 스타일·색·비율을 선택하면 3단계에서 등장인물 선택 후 장면·연출·대사 구성

각 텍스트 단계 끝에는 ‘지금 선택할 것 / 입력 예시 / 선택 후 받을 결과’를 짧게 명시한다. 번호만 나열하고 무엇을 고르는지 생략하지 않는다. 단계별 선택 대상은 1단계 이야기 번호, 2단계 스타일·색·비율, 3단계 등장인물 구성·장면·대사와 개선안, 4단계 프롬프트 번호·장수, 5단계 수정 위치 또는 최종 검수 진행으로 구분한다.

이미지 도구가 결과만 표시하도록 요구하면 해당 응답의 상태·질문은 생성 전에 안내한다. 다음 사용자 응답에서 복원한다. 질문에는 답하고 같은 단계에 머문다. 사용자 취소 전까지 선택·수정을 이후 장면표·프롬프트·그림·대사에 유지하고 충돌하면 최신 요청을 따른다.

## 단계 운영

- 단계별 결과를 먼저 제공하고 사용자의 선택·진행 의사를 기다린다. ‘다음’·‘좋아’는 텍스트 단계의 이동이나 추천 적용으로 처리한다. 이미지 생성은 ‘그려줘’·‘생성해줘’·‘수정해줘’ 등 명확한 제작 의사가 있을 때만 실행한다.
- 초기 ‘이 스킬로 만들어줘’는 기본적으로 1단계 시작 요청이다. 처음부터 ‘추천대로 끝까지 제작’·‘확인 없이 일괄 진행’을 명시하면 이미 받은 승인에 따라 선택과정을 안내하면서 끝까지 진행한다.
- 단계별 작업 중 제작을 명확히 요청했고 필수 설정·참조가 준비되면 같은 제작 승인을 다시 묻지 않는다. 필요한 장면표·프롬프트를 먼저 제시하고 5단계라고 안내해 실행한다. 아직 선택이 필요한 이야기나 장면은 그 부분만 확인한다.
- 4단계에서 번호만 받으면 해당 프롬프트로 1장을 선택한 것으로 요약한다. 제작 의사가 없는 ‘다음’만 받으면 추천 프롬프트 1장을 제안값으로 표시하고 생성 요청 예시를 한 줄로 안내한다. 별도 확인 단계를 추가하지 않는다.
- 이름·주제·설정표·포즈 이미지를 모두 필수로 요구하지 않는다. 기본형 이미지만으로 시작할 수 있다. 이미 정해진 선택은 다시 묻지 않는다.

## 1단계 — 이야기 선택

### 시작 입력과 기본형 연결

- 1단계 시작 시 캐릭터 기본형 이미지를 첨부받아 실제로 확인한다. 이미지가 없으면 ‘파트1에서 확정한 캐릭터 기본형 이미지를 첨부해 주세요’라고 요청하고 1단계에 머문다. 사진 원본을 기본형으로 자동 대체하거나 새 캐릭터를 만들지 않는다.
- 현재 대화에서 기본형을 명확히 확정했다면 그 이미지를 사용할 수 있다. 여러 이미지가 있고 기준이 불명확하면 어느 이미지인지 확인한다. 매 단계 다시 첨부받지 말고 실제 참조할 수 없을 때만 재첨부를 요청한다.
- 이름 미지정은 ‘주인공’으로 진행한다. 주제 미지정은 이미지와 알려진 취향·소품에 어울리는 일상 상황으로 이야기 3안을 함께 추천한다. 사진에서 성격·직업 등 숨은 사실을 추정하지 않는다.
- 설정표가 있으면 그림과 대조한다. 없으면 관찰 가능한 고정 특징 3~5개와 그림체를 정리한다. 기본형과 설명이 충돌하면 사용자에게 해당 항목을 확인한다. 그림에 없는 색·의상·신체 설정을 꾸며 넣지 않는다.
- 고정: 얼굴형·머리/귀·안경·의상·신체 비율·색·선의 특징. 가변: 표정·동작·장면 소품·배경. 컵을 들고 있는 기본형이어도 컵을 신체의 일부로 고정하지 않는다.
- 동물 캐릭터와 사람 캐리커처 모두 지원한다. 상반신 기본형이면 상반신 중심의 장면을 우선 제안한다. 보이지 않는 다리·전신 비율을 이미 정해진 특징으로 설명하지 않는다. 전신이 필요한 이야기는 확장 설정을 먼저 협의한다.

### 주제 입력 안내와 미입력 추천

1단계 시작 안내에 ‘주제는 커피 한 잔, 마감 전날, 스마트폰 알림처럼 짧은 소재나 상황만 적어도 됩니다. 주제를 적지 않으면 어울리는 주제와 이야기 3안을 추천합니다’라고 명시한다. 이미지가 준비되어 있으면 주제 입력을 받기 위해 작업을 멈추지 않는다.

- 주제를 입력했다면 그 범위 안에서 서로 다른 결말의 이야기 3안을 만든다. 짧은 단어나 구절도 충분한 입력이며 자세한 줄거리를 필수로 요구하지 않는다.
- ‘일상’·‘업무’처럼 넓은 주제는 구체적인 상황으로 좁혀 3안에 반영한다. 모호하다는 이유만으로 추가 질문을 반복하지 않는다.
- 주제가 없거나 ‘추천해줘’라고 하면 [주제 추천 자료](references/topics.md)를 참고해 서로 다른 소재 3개를 선택한다. 각 소재에 짧은 시작·기대·방해·결말을 붙여 이야기 3안으로 제시한다. 주제 고르기와 이야기 고르기를 별도 단계로 늘리지 않는다.
- 기본형의 포즈·표정·그림체·소품·보이는 신체 범위와 사용자가 밝힌 용도를 고려한다. 안경을 썼다는 이유로 교사·작가 같은 직업을 추정하지 않는다. 사용자 정보에 없는 경험을 사실로 붙이지 않는다.
- 이야기 추천은 소재 은행을 변형한 창작 제안이며 인기 순위나 실제 경험 데이터가 아니다. 매번 커피 이야기만 추천하지 말고 최근 제안한 소재를 피하여 새 후보를 만든다. 사용자가 같은 소재를 원하면 유지한다.
- 이름·주제·취향이 모두 미지정이어도 기본형을 확인했다면 주인공이라는 이름으로 추천을 진행한다. 빠진 입력을 채우는 별도 설문을 만들지 않는다.
- 사용자가 시작 프롬프트나 사용법을 요청하면 주제 지정 버전과 주제 생략 버전을 함께 보여 준다. 아래 예시의 괄호는 사용자 입력 자리로 안내한다.

주제 지정 시작 예:
```text
my-character-webtoon 스킬로 첨부한 캐릭터의 4컷 웹툰을 만들어줘.
주제: [커피 한 잔 / 마감 전날 / 스마트폰 알림 등]
이 주제로 이야기 3안을 먼저 추천하고 내 선택을 받아 6단계로 진행해줘.
```

주제 생략 시작 예:
```text
my-character-webtoon 스킬로 첨부한 캐릭터의 4컷 웹툰을 만들어줘.
주제는 추천해줘. 이야기 3안을 먼저 보여주고 내 선택을 받아 6단계로 진행해줘.
```

### 이야기 3안 제시

초안 작성 전에 [4컷 재미·품질 기준](references/story-quality.md)을 읽고 적용한다. 기본 분위기는 일상에서 공감할 수 있는 가벼운 코미디다. 감동·교육·홍보 등 다른 목적이 명시되면 그 목적이 우선한다.

- 각 안에 ‘웃음 포인트’와 ‘마지막 컷에서 보이는 반전’을 한 문장씩 추가한다. 세 안의 차이가 제목이나 소품만 바뀐 같은 결말이 되지 않게 한다.
- 1컷의 욕구나 약속을 4컷에서 뒤집거나 되돌려 쓴다. 3컷에서 이미 결말을 모두 보여 주지 않고 4컷의 표정·동작·짧은 대사로 마무리한다.
- 단순히 커피가 식었다·휴대전화를 봤다 같은 사건 기록만으로 세 안을 채우지 않는다. 익숙한 사건에 자기모순·기대 뒤집기·작은 과장·소품 재발견 등 한 가지 장치를 더한다.
- 재미를 위해 조연·사건·설정을 계속 늘리지 않는다. 선택한 인물들의 행동과 관계로 한 가지 작은 상황을 풀어낸다.

일상 공감형·반전 유머형·작은 변화형처럼 결말이 다른 세 안을 추천한다. 각 안을 ‘제목 / 시작 / 기대 / 방해 / 결말 / 전달할 느낌’으로 짧게 비교한다. 제시한 이야기는 창작안임을 전제로 하며 캐릭터의 실제 경험이라고 말하지 않는다.

등장인물 추천·선택은 3단계에서 진행한다. 1단계에서는 이야기 이해에 필요한 역할만 간략히 언급하며 별도 인물 선택이나 외형 확정을 요구하지 않는다. 일상 상황 하나, 기대 하나와 방해 하나를 유지한다. 주제가 명확하면 같은 주제 안에서 세 안을 만들고 하나를 추천한 뒤 선택을 받는다. 이 단계에서는 이미지를 생성하지 않는다.

### 1단계 마지막 선택 안내 — 반드시 제공

- 지금 선택할 것: 이야기 1·2·3안 중 하나. 각각의 웃음 포인트와 추천 이유를 읽고 선택하도록 안내한다.
- 입력 예시: `2안으로`, `2안 / 16:9`, `추천한 1안으로`.
- 선택 후 결과: ‘선택한 이야기에 맞는 스타일 3종·흑백/컬러·비율을 2단계에서 제안합니다. 스타일을 고르면 3단계에서 등장인물을 선택한 뒤 장면·연출·대사를 구성합니다.’
- 사용자가 이야기와 비율을 함께 입력하면 둘 다 저장하고 2단계에서 비율을 다시 묻지 않는다. 스타일·색은 별도 선택임을 알려 준다.

## 2단계 — 스타일·비율 선택

### 웹툰 스타일 추천·선택

선택한 이야기와 기본형을 보고 아래 세 스타일을 비교해 추천 하나와 이유를 설명한다. 비율 표와 함께 제공하고 선택을 기다린다. 이 단계에서는 전체 장면표·대사 후보·이미지 프롬프트를 아직 제공하지 않는다. 정한 스타일에 맞춘 세부 연출은 3단계에서 제안한다. 이미 스타일을 지정했다면 유지한다.

| 선택 | 스타일 | 바뀌는 표현 | 유지할 요소 |
| --- | --- | --- | --- |
| A | 기본형 유지형 | 기본형의 선·색·명암을 그대로 활용 | 인물 특징과 기존 그림체 |
| B | 코믹 웹툰형 | 굵은 윤곽선·선택적 검은 면·분명한 표정·과장된 동작 | 얼굴·머리·안경·의상 등 정체성 |
| C | 감성 일러스트형 | 부드러운 선·가벼운 명암·절제된 표정; 컬러는 선택 | 인물 특징과 장면 연결 |

- 이야기의 웃음이 표정·손동작에 있으면 B형을 추천할 수 있다. 기존 그림체 유지가 우선이면 A형을 추천한다. 모든 이야기에서 같은 스타일을 자동 적용하지 않는다.
- 흑백/컬러는 스타일과 별개로 선택한다. 미지정이면 기본형의 색 사용을 이어 추천한다. 흑백 기본형에 컬러를 요청하면 단순한 색 조합을 제안하고 선택 또는 추천 적용을 받는다. 흑백 선택 시 커피·음식·창빛·피부도 검정·흰색·중성 회색으로 표현하도록 명시하고, 갈색·베이지 같은 부분색을 넣지 않는다. 결과의 부분색도 확인한다. 새 색을 원래 기본형의 사실이라고 설명하지 않는다. 색 변경을 명시했다면 기존 색 고정 조건을 해당 선택값으로 갱신하고 원래 색 유지 명령과 충돌시키지 않는다.
- 고정 특징과 그림체를 구분한다. B·C 선택 시 기본형의 정체성은 유지하면서 선·명암·연출만 선택 스타일로 바꾼다. ‘원래 그림체를 그대로 유지’와 ‘새 그림체 적용’을 프롬프트에 동시에 쓰지 않는다.
- 스타일 선택을 위해 대사나 장면을 자동으로 다른 이야기로 바꾸지 않는다. 과장된 동작은 장면 의미를 유지하는 범위로 조정한다.

### 전체 이미지 비율 추천

이야기 선택 다음 응답에서 아래 비율 표와 사용 목적에 맞는 추천 하나를 보여 준다. 비율은 네 컷을 합친 전체 캔버스 기준이고 개별 컷 비율·캐릭터 신체 비율과 다르다.

| 선택 | 전체 비율 | 추천 용도 | 예시 목표 크기 |
| --- | --- | --- | --- |
| 가로형 | 16:9 | 강의 슬라이드·가로 화면 자료 | 1536×864 |
| 세로형 | 9:16 | 휴대폰 세로 화면용 공유 | 864×1536 |
| 정사각형 | 1:1 | 정사각형 게시물·범용 공유 | 1024×1024 |

- 사용 목적이 있으면 그것에 맞춰 추천한다. 없으면 1:1을 추천하되 선택 전 ‘미정, 1:1 추천’이라고 표시한다. 사용자가 이미 비율을 지정했으면 재질문하지 않는다.
- 컷 배열은 기본 2×2다. 16:9·9:16을 고른다고 자동으로 가로 한 줄·세로 한 줄로 바꾸지 않는다. 별도 배열을 원하면 읽는 순서·구도를 명시해 반영한다. 전체 비율·배열·각 컷 안 여백을 구분한다.
- 표의 크기는 목표 예시이며 도구 지원을 단정하지 않는다. 요청한 비율을 프롬프트에 명시하고 결과의 실제 크기는 접근 가능한 경우 확인한다. 목표와 다르면 사실대로 알리고 도구가 지원하는 수정·재생성 방법을 제시한다. 정확한 크기를 검증하지 않고 맞췄다고 말하지 않는다.

### 2단계 마지막 선택 안내 — 반드시 제공

- 추천 스타일·색·전체 비율 조합과 이유를 간단히 정리한다. 이야기와 함께 받은 16:9 등 이미 확정한 값은 ‘확정’으로 표시하고 재질문하지 않는다.
- 지금 선택할 것: 미정인 스타일 A·B·C, 흑백/컬러, 전체 비율. 예: `B형 / 흑백 / 16:9` 또는 `추천대로`.
- 선택 후 결과: ‘3단계에서 등장인물 구성을 먼저 추천·선택하고, 그 인물에 맞는 네 컷 장면표·대사·재미 보강안을 이어서 보여드립니다.’
- 일부 항목만 답하면 나머지는 방금 제안한 추천을 적용하고 적용값을 알린다. ‘추천대로’·‘다음’이면 추천 조합으로 3단계를 진행한다. 선택을 받기 전에 3단계 전체 내용을 미리 길게 제공하지 않는다.

## 3단계 — 장면·연출·대사 구성

확정된 이야기·스타일·색·전체 비율·배열을 먼저 한 줄로 표시한다. 스타일·비율을 다시 고르게 하지 않는다. 먼저 등장인물을 추천·선택하고, 선택한 구성에 맞는 장면표와 대사를 구체화하여 확인을 받는다. 코믹형이면 표정·동작의 대비, 감성형이면 시선·여백·감정의 흐름, 기본형 유지형이면 기존 그림체의 표현 범위를 활용한다.

### 등장인물 추천·선택 — 장면표 작성 전에 진행

상태는 같은 단계 안에서 `현재: 3/6단계 — 등장인물 선택`과 `현재: 3/6단계 — 장면·대사 확인`으로 구분한다. 인물 선택만 받은 상태에서 4단계로 건너뛰지 않는다.

- 3단계에 처음 진입하면 선택한 이야기·스타일에 맞춰 ‘주인공 단독 / 주인공과 조연 1명 / 주인공과 사물 의인화’ 중 적합한 구성 2~3개를 비교한다. 표에는 ‘구성 / 추가 인물의 역할·관계 / 재미가 달라지는 지점 / 짧은 대화 예’를 넣고 하나를 추천한다. 억지로 세 유형을 모두 넣거나 조연을 자동 추가하지 않는다.
- 대화·반응으로 결말이 선명해지면 주인공과 조연 1명, 총 2명을 우선 추천한다. 표정 대비만으로 성립하면 단독을 추천한다. 의인화는 창작 제안으로 표시하고 선택한 경우에만 적용하며 인물 수에 포함한다. 3명 이상은 사용자가 원하거나 이야기상 필요한 경우에만 제안한다. 이미 인물 구성을 명시했으면 다시 고르게 하지 않는다.
- 추가 인물은 이야기 안의 가상 동료·친구·가족 등으로 제안하며 실제 관계나 직업으로 단정하지 않는다. 주인공과 구별되는 헤어·안경 유무·의상·실루엣 등 외형 2~3개도 이 단계에서 함께 제안한다. 이미지가 있으면 확인해 인물별 참조 역할을 연결하고, 없으면 ‘제안 외형’으로 진행한다. 별도 첨부나 캐릭터 생성 단계를 필수로 추가하지 않는다.
- 지금 선택할 것과 예시를 명확히 안내한다: `동료 1명 / 외형은 추천대로`, `주인공 단독`, `추천 구성으로`. 선택 후 같은 3단계에서 해당 인물에 맞는 네 컷 장면표·화자·정확한 대사·마지막 대사 2안을 제공한다. 인물 선택 전에 완성 장면표와 대사를 확정해 쏟아내지 않는다. 전체 단계는 6개이며 3단계 안에서 인물 선택 → 장면·대사 확인 순서로 진행한다.
- 사용자가 `추천대로 장면까지`처럼 일괄 적용을 원하면 추천 인물을 표시하고 같은 응답에서 장면표까지 제공한다. 이미 단독을 명시했으면 조연 추가를 다시 권하지 않는다. 선택한 이야기·결말은 유지하되 인물 추가로 기존 확정 대사를 바꿔야 하면 수정안을 먼저 보여 준다.
- 진행 중 인물 추가 요청은 전체를 1단계부터 반복하지 않고 3단계의 관계·외형·등장 컷·대사 중 바뀌는 항목만 갱신한 뒤 두 프롬프트에 반영한다. 스킬 업데이트 요청만으로 현재 제작물에 인물을 추가하거나 재생성하지 않는다.

### 재미와 내용 품질을 높이는 추천

- 이미 고른 스타일을 반복 추천하지 않는다. 선택한 이야기에서 ‘독자가 기대하는 것 / 예상이 어긋나는 지점 / 마지막 컷의 그림·대사’가 무엇인지 한 줄씩 설명한다.
- 추천 연출은 추상적인 ‘더 재미있게’ 대신 구체적 표정·시선·손동작·거리·소품 크기의 대비로 제안한다. 기본형을 유지할 부분과 과장할 부분을 구분한다.
- 장면표를 작성한 뒤 개선할 핵심 2~3개를 ‘수정 위치 / 현재 표현 / 추천 표현 / 이유’로 짧게 제시한다. 이미 충분하면 불필요한 수정 항목을 꾸며내지 않고 잘 작동하는 요소를 설명한다.
- 마지막 대사는 2개 후보를 짧게 비교하고 하나를 추천한다. 후보별 다른 효과(능청·반전·과장 등)를 설명한다. 사용자가 이미 대사를 확정했으면 새 대사로 바꾸지 않고 연출만 보완한다.
- 예: ‘커피 가루를 턴다’ → ‘가루는 아주 조금, 얼굴은 수사관처럼 진지하게’는 행동과 표정의 크기 차이로 웃음을 만든다. ‘아직 남았네?’와 마지막 동작의 기능이 겹치지 않게 한다.
- 사용자에게 고른 이야기를 다시 세 안으로 고르게 하지 않는다. 개선은 기존 이야기 안에서 제안하고 사용자가 일부만 선택할 수도 있게 한다. 한 번에 답할 수 있는 추천 조합을 마지막에 정리한다.

### 장면과 짧은 대사 설계

2단계에서 정한 스타일·비율을 반영해 아래 장면표를 제공한다. 이 단계에서는 이미지를 생성하지 않는다. 코믹형·감성형 등 선택한 표현 방식에 따라 표정·구도·말투를 조정하되 이야기의 결말은 유지한다.

| 컷·위치 | 등장인물·화자 | 역할 | 중심 동작 | 표정 | 소품·상태 | 배경·구도 | 넣을 대사 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1·왼쪽 위 | 인물·화자 | 시작 | 한 가지 행동 | 눈·입의 연출 | 종류·형태·위치 | 장소·시점 | 짧은 한 문장 |
| 2·오른쪽 위 | 인물·화자 | 기대 | 한 가지 행동 | 변화 | 이어지는 상태 | 장소·구도 | 짧은 한 문장 |
| 3·왼쪽 아래 | 인물·화자 | 방해·전환 | 한 가지 행동 | 반응 | 들고/내려둔 위치 | 장소·구도 | 짧은 한 문장 |
| 4·오른쪽 아래 | 인물·화자 | 결말 | 한 가지 행동 | 감정이 보이게 | 결과 상태 | 결말이 보이는 구도 | 짧은 한 문장 |

- 인물별 등장 컷·역할·좌우 위치·시선과 정확한 화자를 장면표에 명시한다. 조연은 질문·방해·대조·반응 중 이야기에서 필요한 역할을 맡기고 마지막 컷의 재미에 기여하게 한다. 모든 인물을 매 컷에 넣을 필요는 없다. 한 컷의 중심 행동은 하나로 유지하고 대화는 네 컷에 나누며 말풍선 꼬리로 화자를 구분한다. 의인화한 사물은 표정·입 유무·말하는 컷과 소품 상태를 정한다.
- 대사와 말풍선을 기본 포함한다. 컷당 대사 한 문장·10자 이내를 우선하되 자연스러운 의미를 위해 필요하면 사용자와 조정한다. ‘무대사’·‘글자 없이’를 명시하면 대사와 말풍선을 모두 제외한다.
- 대사는 행동·표정과 연결하고 마지막 대사로 결말을 명확하게 한다. 사용자 대사가 있으면 의미와 표현을 임의로 바꾸지 말고 길거나 어색한 경우 수정안을 제안한다.
- 고정 외형은 기본형에서 이어 쓰고 선·색·명암·표정 과장은 선택한 웹툰 스타일을 따른다. 말풍선 공간을 구도 안에 미리 확보하고 얼굴·손·핵심 소품을 가리지 않도록 배치 위치를 정한다. 제목은 별도 선택이며 기본으로 추가하지 않는다.
- 생성 전에 한국어 프롬프트의 오타·의도하지 않은 한자 혼입을 점검한다. 마지막 대사는 그림을 보며 뜻이 곧바로 연결되는지 확인하고, 무엇을 금지하거나 원하는지 모호한 표현은 짧고 구체적인 동사로 보완한다. 예: 가루를 아끼는 장면에서 ‘한 알도 안 돼’보다 ‘한 톨도 못 버려’를 검토한다. 확정 대사는 허락 없이 바꾸지 않는다.
- 스마트폰 화면·메모·포장지의 작은 글자에 이야기를 의존시키지 않는다. 화면은 단순 아이콘·토글·손동작으로 표현하고 읽어야 할 문구는 확정된 말풍선에만 넣는다.
- 한 컷에는 중심 동작 하나를 두고 반복 소품의 모양·색·위치와 상태를 연결한다. 불명확한 결말은 동작·표정도 보강하며 대사만으로 문제를 덮지 않는다.
- [4컷 재미·품질 기준](references/story-quality.md)에 따라 네 컷의 차이, 마지막 컷의 보상, 대사의 역할을 점검한다. 약하면 장면표를 먼저 보완하고 한 줄로 이유를 설명한다. 사용자가 고른 이야기 자체는 임의로 바꾸지 않는다.
### 3단계 마지막 선택 안내 — 반드시 제공

- 지금 선택할 것: 인물 구성 선택 전이면 등장인물 구성·제안 외형, 선택 후 장면표를 제공했으면 장면·연출·대사 수정 여부와 마지막 대사 후보. 이미 확정한 스타일·비율을 다시 고르게 하지 않는다.
- 입력 예시: `장면은 추천대로 / 마지막 대사 1번`, `4컷 표정만 더 능청스럽게`, `추천대로 다음`.
- 선택 후 결과: 인물 선택 전에는 ‘선택한 인물로 같은 3단계에서 장면표와 대사를 구성합니다’, 장면표 확인 단계에서는 ‘확인한 장면표와 대사로 4단계 이미지 프롬프트 2안을 작성합니다’라고 안내한다.
- 인물 추천에 대한 ‘추천대로’·‘다음’이면 추천 인물로 같은 3단계 장면표를 작성한다. 장면표까지 제공한 후의 ‘추천대로’·‘다음’이면 제안한 장면표와 추천 대사를 확정하고 4단계로 이동한다. 수정 요청이면 먼저 해당 부분을 갱신하고 다른 설정은 유지한다.

## 4단계 — 이미지 프롬프트 2안 작성

[프롬프트 템플릿](references/prompts.md)을 확정된 조건으로 채운 **완전한 프롬프트 두 개**를 별도 평문 코드 블록으로 제공한다. 공통 지시를 앞에서 참조하도록 생략하지 않는다. 출력 전에 초안의 오타·불필요한 외국어·미완성 지시를 교정하고 최종 프롬프트 1번·2번 두 개만 제공한다. 잘못된 초안과 교체본을 함께 나열하거나 세 번째 코드 블록으로 정정본을 덧붙이지 않는다.

| 번호 | 이름 | 유지할 것 | 달리할 것 |
| --- | --- | --- | --- |
| 1 | 균형·가독성형 | 선택한 이야기·스타일·색·비율·배열·장면·확정 대사 | 안정된 구도, 동작이 한눈에 보이는 거리, 절제된 표정 과장 |
| 2 | 코믹 연출 강조형 | 1안과 같은 고정 조건과 이야기 결말 | 마지막 컷의 표정·손동작·시선·클로즈업 대비를 더 강조 |

- 두 프롬프트의 차이를 짧게 비교하고 하나를 추천한다. 두 번째 안을 만드는 이유로 확정 대사를 바꾸거나 새로운 인물·소품·사건을 추가하지 않는다.
- 감성형·기본형 유지형을 고른 경우 2안도 선택한 스타일 안에서 표정·동작 대비를 높인다. 다른 그림체나 전혀 다른 정서로 바꾸지 않는다. 사용자가 코미디를 원하지 않으면 2안을 ‘감정·장면 연출 강조형’으로 이름과 연출을 조정한다.
- 두 안 모두 기본형 역할, 고정 특징, 선택 스타일·색, 전체 비율·배열·읽는 순서, 인물별 참조·외형·관계·등장 컷·화자·인물 수, 네 동작·표정·소품 상태·배경, 정확한 대사·말풍선 위치, 추가 글자 유무·누적 수정을 완전히 포함한다.
- [재미·품질 기준](references/story-quality.md)의 생성 전 점검에 대조하여 장면표와 각 프롬프트의 설정이 일치하는지 확인한다. 코믹 연출 강화 때문에 소품 상태·중심 동작·이야기 순서가 달라지지 않게 한다.
- 무대사 선택이면 두 안 모두 대사·말풍선을 제외한다. 그 외에는 대사 포함을 기본으로 하고 ‘글자 없음’ 조건과 혼용하지 않는다.
- 두 프롬프트를 제공한 것이 이미지 두 장 생성 승인은 아니다. 기본은 사용자가 고른 한 안으로 웹툰 한 장이다. 두 안 비교를 명시하면 각각 한 장씩 생성한다.

### 4단계 마지막 선택 안내 — 반드시 제공

지금 선택할 것: 프롬프트 1·2번과 제작 장수.
- 한 안으로 제작: `2번 프롬프트로 1장 생성해줘`.
- 두 안 비교: `1·2번 프롬프트로 각각 1장씩, 총 2장 생성해줘`.
선택 후 결과: ‘5단계에서 선택한 프롬프트로 이미지를 생성합니다.’

명확한 생성 요청이 이미 있고 번호가 미정이면 직전 추천 프롬프트로 한 장을 제작한다고 안내하고 재승인 없이 실행한다. 프롬프트만 요청했으면 생성하지 않는다. 사용자가 프롬프트 한 개만 요구하면 그 지시를 우선한다.

## 5단계 — 웹툰 생성·수정

현재 이미지 도구의 사용 지침을 우선하여 실제 제작한다. 모델명·API·외부 계정·유료 구독을 필수로 요구하지 않고 생성 한도·해제 시간을 추측하지 않는다.

- 기본형은 정체성 기준, 추가 포즈는 동작 참고다. 최초 생성은 기본형을 참조하고 수정은 최신 웹툰 결과와 기본형을 필요한 역할로 지정한다. 안내 스크린샷·무관한 캐릭터를 참조에 섞지 않는다.
- 로컬 참조는 이미지 보기 도구로 확인 후 `referenced_image_paths`에 전달한다. 경로 없는 대화 이미지는 `num_last_images_to_include`로 모두 포함하는 최소 개수를 지정한다. 두 방식을 동시에 쓰지 않는다. 모두 포함할 수 없으면 필요한 이미지만 재첨부받는다.
- 생성 직전 별도 설명 문단 첫 줄에 **‘현재: 5/6단계 — 웹툰 생성·수정’**을 명확히 표시한다. 이어서 선택한 프롬프트 번호·제작 장수·스타일·색·비율·배열·대사 여부를 안내한다. ‘이미지를 만들겠습니다’라는 말만 하고 단계 번호를 생략하지 않는다.
- 생성 전에 완료 후 입력 방법도 안내한다: `오른쪽 아래 컷의 표정만 더 진지하게 수정해줘` / `다음 — 6단계 최종 검수`.
- 이미지 한 장이면 후보 `프롬프트 2번 · v1`처럼 프롬프트와 버전을 연결한다. 두 장 비교이면 1번→2번 순서로 표시해 완료 순서 때문에 번호가 바뀌지 않게 한다. 단계 설명이나 후보 번호를 웹툰 그림 안에 추가하지 않는다.
- 도구가 이미지 뒤 텍스트를 허용하면 결과 바로 아래에 **‘현재: 5/6단계 완료 — 이미지 확인’**과 ‘수정할 컷을 알려 주시거나 다음으로 6단계 검수를 진행해 주세요’를 짧게 덧붙인다. 이미지 뒤 텍스트를 금지하면 생성 전 안내를 지키고 다음 사용자 응답 첫 줄에 5단계 결과임을 복원한다. 금지된 응답에 텍스트를 강제하지 않는다.
- 선택한 비율에 맞는 캔버스와 컷 안 구도를 프롬프트에 명시한다. 핵심 소품의 바닥·손잡이·접촉 지점은 컷 테두리에서 여유를 두어 온전히 보이게 한다. 클로즈업에서도 핵심 동작의 일부를 잘라내지 않는다. 가능한 경우 결과의 실제 가로·세로를 측정하고 교차곱으로 비율을 확인한다. 근사 비율은 ‘정확한 16:9’라고 보고하지 않는다. 정확한 출력이 필요하면 지원되는 비율 수정 방법을 제안한다.
- 기본 배경은 장면 장소이며 `transparent_background` false를 사용한다. 사용자 지정 배경이 우선한다. `image_gen.imagegen` 결과는 `generatedImage(result)`로 표시하고 base64를 출력하지 않는다. 생성물 표시·저장은 현재 도구 지침을 따른다.
- 생성 뒤 텍스트가 금지되는 도구이면 입력 방법을 미리 안내하고 이미지로 응답을 마친다. 다음 응답에서 비교·검수를 이어간다. 도구가 없으면 불가 사실과 완성 프롬프트를 제공하고 실제 생성했다고 말하지 않는다.

### 실제 결과 점검·부분 수정

| 점검 | 확인 기준 |
| --- | --- |
| 이야기·재미 | 네 컷 순서·기대·전환·결말·중심 동작, 마지막 컷의 시각적 반전과 대사 |
| 캐릭터·스타일 | 선택한 인물 수·등장 컷, 인물별 외형 구분·좌우 관계·화자, 기준 외형의 정체성, 선택한 선·색·명암·표정 과장의 일관성 |
| 소품·손 | 접촉·손가락·손잡이·반복 소품의 형태와 위치 |
| 화면 | 전체 비율·정확히 네 컷·배열·잘림·말풍선 여백 |
| 대사 | 확정 문구의 한글 오탈자·누락·화자·말풍선 위치 |

실제 결과를 보고 ‘컷 위치 → 관찰 문제 → 유지할 요소 → 수정안’을 제시한다. 재미 평가는 편집적 판단이며 독자 반응을 확인한 사실처럼 단정하지 않는다. 이야기의 반전이 생성 과정에서 빠졌는지도 확인한다. 확인하지 못한 비율·글자를 검수했다고 말하지 않는다. 가장 중요한 문제부터 수정하도록 추천하고 명확한 수정 요청이면 바로 실행한다.

수정은 컷 번호와 실제 위치를 함께 지정하고 다른 세 컷·전체 비율·배열·확정 대사·그림체를 유지하도록 한다. 대사 수정이면 선택한 문구만 바꾼다. 수정 뒤 다른 컷도 바뀔 수 있으므로 전체를 다시 비교하며 정확한 부분 보존을 보장하지 않는다.

한글 오류가 반복되면 무대사 바탕에 편집 가능한 말풍선을 얹는 대안을 제안한다. 기존 대사 포함 이미지를 무대사 원본이라고 부르지 않는다. 무대사 바탕이 필요하면 별도로 만들거나 실제 있는 무대사 원본을 사용한다. 요청 시 사용 가능한 문서·슬라이드 기능으로 제작하며 지원·검수 범위를 알린다.

한 컷이 계속 어긋나면 해당 컷만 생성해 교체하는 방법을 제안한다. 합성 도구가 없으면 별도 컷과 교체 안내만 제공하고 최종 합성 완료라고 하지 않는다. 기본형·선택 스타일·색·장면표·프롬프트·비율·대사·후보·버전을 연결하고 원본은 덮어쓰지 않는다. 확정·다음 요청이면 6단계로 이동한다.

## 6단계 — 검수·최종 완성

기본은 대사가 들어간 완성본을 최종 점검한다. 무대사 요청이면 해당 결과를 확정하고 대사를 강제로 추가하지 않는다. 이전 무대사 결과에서 대사 추가를 원하면 장면표의 짧은 문구와 말풍선 위치를 보여 준 뒤 명확한 추가 요청에 따라 편집한다. 이미 문구와 제작 요청을 받았으면 재승인 없이 실행한다.

최종 확인 항목은 선택 스타일·색·전체 비율·배열, 네 장면 연결과 마지막 컷의 재미 장치, 캐릭터 고정 특징, 소품 연속성, 추가 인물의 외형·등장 컷·화자, 확정 대사의 정확성·가독성과 말풍선 가림이다. 한글이나 비율이 어긋났으면 그 부분을 알리고 수정 또는 현재 버전 확정을 선택하게 한다.

완성 시 실제로 확보한 것만 정리한다.
- 기본형·선택 주제와 이야기·웹툰 스타일·색·전체 비율·배열·대사 포함 여부·결과 버전.
- 최종 웹툰과 수정 이력. 무대사본은 실제로 만들었거나 사용자가 요청했을 때만 결과에 포함한다. 기본 절차로 추가 생성하지 않는다.
- 최종 장면표·사용한 프롬프트·대사·다음 편의 고정 조건. 짧으면 대화로 제공하고 파일 요청 시 현재 저장 지침을 따른다.
- 파일명 제안: `[캐릭터]_[이야기]_16x9_대사_v1.png` 등. 파일명 제안만으로 저장 완료라고 하지 않는다.

새 이야기는 같은 기본형과 선택 스타일을 이어 쓰고 주제부터 바꾼다. 사용자가 용도를 바꾸면 비율을 다시 추천한다. 문구만으로 완벽한 외형·정확한 한글을 보장하지 않는다.

## 완료 점검

- 1단계에서 기본형을 확인하고 짧은 주제 입력·주제 생략을 지원하며 이야기만 선택하고 등장인물 상세 선택은 3단계로 이어지는가.
- 3단계에서 등장인물 구성과 외형을 먼저 선택받고 그에 맞는 등장 컷·관계·화자·대사를 구성하며, 동일한 인물 설정이 두 프롬프트와 검수까지 이어지는가. 단독 선택과 현재 제작물을 임의로 바꾸지 않는가.
- 2단계에서 스타일·색·전체 비율만 추천·선택하고 3단계 장면표와 대사를 미리 쏟아내지 않는가.
- 3단계 안에서 인물 선택 → 장면·대사 확인이 이어지고, 확정 스타일·비율에 맞는 재미 보강안을 제공하는가.
- 4단계에서 독립적으로 복사할 수 있는 완전한 프롬프트 두 개를 제공하고 차이·추천·선택 방법을 안내하는가. 두 안의 확정 대사·설정은 동일한가.
- 기본은 대사 포함이며 무대사본을 추가로 강제 생성하지 않는가.
- 실제 결과의 그림·글자·비율을 점검하고 수정의 영향을 확인하는가.
- 이야기의 웃음 포인트·시각적 반전·대사의 역할을 확인하고 실제 결과에서 반영됐는지 구분하는가.
