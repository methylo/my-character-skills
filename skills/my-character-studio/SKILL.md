# 내 캐릭터·웹툰 만들기

`my-character-studio` 하나로 캐릭터 제작과 4컷 웹툰 제작을 진행한다. 사용자의 목적과 실제로 참조할 수 있는 이미지에 따라 아래 절차를 선택하고 해당 문서를 읽는다. 모든 제작 지침과 참고 자료는 이 스킬 안에 있다.

| 시작 자료와 목적 | 읽을 제작 절차 | 첫 결과 |
| --- | --- | --- |
| 인물 사진으로 캐릭터 만들기 | [캐릭터 제작 4단계](references/character-workflow.md) | 사진에서 유지할 특징과 콘셉트 3안 |
| 기존 캐릭터의 포즈·그림체·실루엣 바꾸기 | [캐릭터 제작 4단계](references/character-workflow.md)의 ‘기본형으로 포즈·실루엣 확장’ | 기준 이미지와 유지할 특징을 확인하고 원하는 변경을 제안하거나 제작 |
| 완성 캐릭터로 웹툰 만들기 | [4컷 웹툰 제작 6단계](references/webtoon-workflow.md) | 기본형에서 유지할 특징, 이야기 3안과 각 안의 추천 인물 |
| 웹툰 소재 찾기 또는 다음 편 여러 개 추천받기 | [4컷 웹툰 제작 6단계](references/webtoon-workflow.md)의 ‘여러 에피소드 추천’ | 별도 주제 입력 없이도 서로 다른 에피소드 후보와 추천 순서 |
| 인물 사진부터 웹툰까지 만들기 | 캐릭터 제작 4단계 → 4컷 웹툰 제작 6단계 | 캐릭터 제작부터 시작하고 기준 이미지 확정 뒤 웹툰으로 이어감 |

- 목적과 이미지가 명확하면 요청한 작업의 1단계부터 진행한다. 이미지가 명확하고 목적이 생략되면 사진은 캐릭터 제작, 완성 캐릭터는 웹툰 제작으로 시작한다.
- 사용법을 묻거나 작업과 자료를 지정하지 않고 스킬만 호출하면 ‘사진으로 내 캐릭터 만들기’, ‘완성한 캐릭터로 4컷 웹툰 만들기’, ‘사진부터 웹툰까지 만들기’를 작업명으로 안내한다. 각 작업에 필요한 이미지 종류를 짧게 덧붙인다. 할 작업을 정했고 이미지가 필요하면 사진 또는 완성 캐릭터 이미지를 요청한다.
- 사진만 있고 웹툰을 원하면 캐릭터 제작부터 시작한다. 사진과 완성 캐릭터가 모두 있고 어느 쪽이 기준인지 모호하면 기준 이미지 한 장을 확인한다. 작업하거나 수정 중인 이미지가 명확하면 진행 중인 작업에서 이어서 진행한다.
- 웹툰 소재나 에피소드 기획만 요청하면 주어진 정보로 후보를 제안한다. 기본형마다 달라지는 외형·구도 확인은 해당 편 제작을 시작할 때 진행한다.

사용자 안내와 상태 표시는 작업명과 단계명으로 작성한다. 예시는 `캐릭터 만들기 1/4 · 콘셉트 선택`과 `4컷 웹툰 만들기 1/6 · 이야기 선택`이다. 이어서 진행하라는 답변, 선택, 수정, 이미지 생성 요청은 진행 중인 작업의 지침에 따라 처리한다.

## 사진부터 웹툰까지 만들 때

1. 캐릭터 제작 4단계에서 기준 후보와 버전을 사용자 선택에 따라 확정한다. 웹툰까지 요청한 경우, 기준 이미지가 확정되면 [4컷 웹툰 제작 절차](references/webtoon-workflow.md)를 읽고 웹툰 1단계를 시작한다. 캐릭터만 요청했다면 기본형과 재사용 문구를 제공한다.
2. 같은 대화의 확정 이미지를 실제로 참조할 수 있으면 그대로 사용한다. 확인한 특징과 선택한 설정도 가져오되, 원본 사진이나 설정 문구를 기본형 이미지의 대체물로 사용하지 않는다. 확정 이미지를 참조할 수 없을 때만 다시 첨부하도록 안내한다.
3. 연속 제작 목표를 웹툰 이미지 생성 승인으로 해석하지 않는다.

## 웹툰 참고 자료

- [주제 추천](references/topics.md)에서 주제를 지정하지 않은 요청의 소재를 고른다.
- [4컷 이야기 품질 기준](references/story-quality.md)을 이야기와 장면 구성, 생성 전 점검에 적용한다.
- [이미지 프롬프트 템플릿](references/prompts.md)으로 4단계 프롬프트 2안을 작성한다.

## 공통 호출 예시

```text
my-character-studio 스킬로 첨부한 내 사진으로 캐릭터를 만들어줘. 콘셉트 3안부터 보여줘.
```

```text
my-character-studio 스킬로 첨부한 완성 캐릭터로 4컷 웹툰을 만들어줘. 주제와 이야기 3안부터 추천해줘.
```

```text
my-character-studio 스킬로 첨부한 내 사진에서 캐릭터를 만들고, 기본형을 확정한 뒤 4컷 웹툰까지 이어서 진행해줘.
```

```text
my-character-studio 스킬로 기본형의 얼굴과 그림체를 유지해줘.
두 번째 첨부 사진에서는 자세만 참고하고, 같은 캐릭터의 새 포즈로 1장 생성해줘.
```

```text
my-character-studio 스킬로 이 캐릭터의 다음 4컷 웹툰 에피소드를 5편 추천해줘.
주제는 추천해주고 제목, 시작 상황, 마지막 컷의 반전, 추천 인물을 보여줘.
```

```text
my-character-studio 스킬로 첨부한 사진의 캐릭터를 만들어줘.
색상은 컬러, 그림체는 펜 선화로 정하고, 콘셉트 3안을 먼저 추천해줘.
```
