# 내 캐릭터·웹툰 만들기

`my-character-studio` 하나로 캐릭터 제작과 4컷 웹툰 제작을 진행한다. 사용자의 목적과 실제로 참조할 수 있는 이미지에 따라 아래 절차를 선택하고 해당 문서를 읽는다. 모든 제작 지침과 참고 자료는 이 스킬 안에 있다.

| 시작 자료와 목적 | 읽을 제작 절차 | 첫 결과 |
| --- | --- | --- |
| 인물 사진으로 캐릭터 만들기 | [캐릭터 제작 4단계](references/character-workflow.md) | 사진에서 유지할 특징과 콘셉트 3안 |
| 완성 캐릭터로 웹툰 만들기 | [4컷 웹툰 제작 6단계](references/webtoon-workflow.md) | 기본형에서 유지할 특징과 이야기 3안 |
| 인물 사진부터 웹툰까지 만들기 | 캐릭터 제작 4단계 → 4컷 웹툰 제작 6단계 | 캐릭터 제작부터 시작하고 기준 이미지 확정 뒤 웹툰으로 이어감 |

- 목적과 이미지가 명확하면 해당 파트의 1단계부터 진행한다. 이미지가 명확하고 목적이 생략되면 사진은 캐릭터 제작, 완성 캐릭터는 웹툰 제작으로 시작한다.
- 이미지가 없더라도 사용법을 물었으면 두 가지 시작 방법을 안내한다. 제작을 요청했다면 해당 파트에 필요한 사진 또는 완성 캐릭터 이미지를 요청한다. 목적도 자료도 불명확하면 사진으로 시작할지, 완성 캐릭터로 웹툰부터 시작할지 간단히 확인한다.
- 사진만 있고 웹툰을 원하면 캐릭터 제작부터 시작한다. 사진과 완성 캐릭터가 모두 있고 어느 쪽이 기준인지 모호하면 기준 이미지 한 장을 확인한다. 작업하거나 수정 중인 이미지가 명확하면 현재 파트에서 이어서 진행한다.

## 두 파트를 이어서 진행할 때

1. 캐릭터 제작 4단계에서 기준 후보와 버전을 사용자 선택에 따라 확정한다. 웹툰까지 요청한 경우, 기준 이미지가 확정되면 [4컷 웹툰 제작 절차](references/webtoon-workflow.md)를 읽고 웹툰 1단계를 시작한다. 캐릭터만 요청했다면 기본형과 재사용 문구를 제공한다.
2. 같은 대화의 확정 이미지를 실제로 참조할 수 있으면 그대로 사용한다. 확인한 특징과 선택한 설정도 가져오되, 원본 사진이나 설정 문구를 기본형 이미지의 대체물로 사용하지 않는다. 확정 이미지를 참조할 수 없을 때만 다시 첨부하도록 안내한다.
3. 현재 파트와 단계를 `캐릭터 1/4` 또는 `웹툰 1/6`처럼 표시한다. 이어서 진행하라는 답변, 선택, 수정, 이미지 생성 요청은 현재 파트의 지침에 따라 처리한다. 연속 제작 목표를 웹툰 이미지 생성 승인으로 해석하지 않는다.

## 웹툰 참고 자료

- [주제 추천](references/topics.md)에서 주제를 지정하지 않은 요청의 소재를 고른다.
- [4컷 이야기 품질 기준](references/story-quality.md)을 이야기와 장면 구성, 생성 전 점검에 적용한다.
- [이미지 프롬프트 템플릿](references/prompts.md)으로 4단계 프롬프트 2안을 작성한다.

## 공통 호출 예시

```text
my-character-studio 스킬로 첨부한 내 사진으로 캐릭터를 만들어줘. 콘셉트 3안부터 보여줘.
```

```text
my-character-studio 스킬로 첨부한 완성 캐릭터로 4컷 웹툰을 만들어줘. 주제와 이야기 3안부터 추천해줘.
```

```text
my-character-studio 스킬로 첨부한 내 사진에서 캐릭터를 만들고, 기본형을 확정한 뒤 4컷 웹툰까지 이어서 진행해줘.
```
