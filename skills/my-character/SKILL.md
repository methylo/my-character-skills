# 내 캐릭터 만들기

호출명은 `my-character`와 ‘내 캐릭터 만들기’로 통일한다. 이전 호출명 `image-caricature`와 ‘나를 닮은 캐리커처 만들기’로 요청해도 같은 4단계로 진행한다. 기본형이 확정되면 `my-character-webtoon`(내 캐릭터로 4컷 웹툰 만들기)에 첨부해 이어서 활용할 수 있다.

사진을 단순히 펜화로 옮기지 말고 닮은 특징을 선별하여 세련되고 코믹한 성인 캐리커처로 만든다. 한 가지 콘셉트를 모든 사람에게 적용하지 말고 사진·사용 목적·사용자의 취향에 맞는 여러 방향을 추천한다.

## 4단계 안내

처음 시작하거나 진행 상황을 물으면 다음 표를 보여 준다. 이후에는 현재 단계·확정 설정·지금 선택할 것·입력 예시·선택 후 결과를 간결하게 알린다.

| 단계 | 하는 일 | 결과 | 입력 예 |
| --- | --- | --- | --- |
| 1. 콘셉트 선택 | 사진 특징 분석, 콘셉트 A·B·C 추천 | 원하는 인물 연출 | B형으로 |
| 2. 표현 방향·스타일 선택 | 선택한 콘셉트에 맞는 닮음·멋스러움·코믹함과 그림체·색·구도 비교 | 표현 조합 | 멋스러움 중심, 표정은 코믹하게 |
| 3. 이미지 프롬프트 작성 | 확정한 선택을 반영한 복사용 프롬프트 작성 | 최종 프롬프트·제작 장수 | 이 프롬프트로 1장 생성해줘 |
| 4. 이미지 생성 | 실제 제작, 결과 선택·수정·기본형 정리 | 이미지 결과·기본형 | 2번을 더 코믹하게 수정해줘 |

1단계는 ‘어떤 인물로 연출할지’, 2단계는 ‘어떤 표현 방향과 그림체로 그릴지’, 3단계는 ‘선택을 실제 생성 지시문으로 작성’, 4단계는 ‘이미지 제작’을 담당한다. 2단계의 선택을 받기 전에 긴 이미지 프롬프트를 작성하거나 생성으로 건너뛰지 않는다. 단계 수는 이 네 개로 유지하고 결과 비교·수정·확정은 4단계 안에서 진행한다.

이미지 도구가 결과만 표시하도록 요구하는 응답 외에는 다음 상태를 일반 문장으로 표시한다.

현재: 1/4단계 — 콘셉트 선택
설정: [콘셉트 또는 미정] / [상반신 등 구도] / [그림체·색] / [분위기]
반영 사항: [누적 요청 또는 없음]
다음: [선택·생성·수정·확정 중 다음 행동]

이미지 생성 뒤에는 후보 번호·버전을 추가한다. 기존 대화에서 선택한 설정을 유지하고 질문에는 답한 뒤 현재 단계에 머문다.

## 기본 표현 기준

- 기본 구도: 머리 전체부터 허리 위까지의 상반신. 손동작을 넣으면 손이 잘리지 않게 여백을 확보한다. 전체 캔버스 비율은 구도와 구분한다. 미지정이면 상반신에 세로 3:4를 추천값으로 안내하고 별도 필수 질문을 추가하지 않는다. 사용자가 1:1·16:9·9:16 등 비율을 주면 유지하고 생성 후 실제 크기로 확인한다.
- 기본 그림체: 굵기 변화가 있는 과감하고 유려한 흑백 펜 선, 선택적인 검은 면, 최소한의 명암, 흰색 배경, 글자 없음. 얼굴 전체를 촘촘한 해칭·교차선으로 덮거나 피부·옷 주름을 사진처럼 묘사하지 않는다. 흰 면을 충분히 남기고 특징을 적은 선으로 선별한다. 연필 등 다른 그림체를 선택했으면 이 펜선 제한을 그대로 강제하지 않는다.
- 닮은 특징: 사진에서 확인한 안경·머리·눈매·얼굴형 등 3가지를 유지한다. 모든 인물에게 안경이나 올린 머리를 새로 붙이지 않는다.
- 멋스러움: 헤어와 의상 실루엣을 정돈하고 얼굴 윤곽을 간결하게 표현한다. 눈썹·입꼬리·자세로 자신감을 더한다. 인물이 달라질 정도로 미화하지 않는다.
- 코믹함: 머리를 상체보다 조금 크게, 선택한 안경·머리·눈매·표정을 특징에 맞게 과장한다. 비대칭 미소·고개 기울기·손동작을 활용한다. 정밀 초상 스케치나 평범한 프로필 그림에 머물지 않는다.
- 과장 기본값: 중간. 낮게는 닮음 중심, 중간은 닮음과 코믹함의 균형, 높게는 선택한 특징과 표정·동작을 더 강조한다. 알아보기 어려운 왜곡은 피한다.
- 성인 사진은 성인 캐리커처로 표현한다. 2등신·치비·유아형을 기본으로 적용하지 않는다.
- 얼굴 중심 또는 전신을 요청하면 기본 상반신 조건을 대체한다. 얼굴 중심이면 허리·손동작·머리와 상체의 크기 비교 지시를 삭제하고 얼굴·머리의 선택 특징만 과장한다. 얼굴 중심은 머리부터 어깨 윗부분, 전신은 자연스러운 성인 캐리커처 비율로 표현한다. 2등신은 별도 요청에만 적용한다.
- 색상·배경·그림체는 사용자 지정이 기본값보다 우선한다. 손동작과 소품은 콘셉트 추천에 명시하고 불필요한 소품을 추가하지 않는다.

## 콘셉트 추천 라이브러리

다음은 사람을 분류하는 성격·직업 판정이 아니라 시각 연출 선택지다. 사진만으로 실제 성격·직업을 단정하지 않는다. 직업을 알 수 없으면 ‘강연자’ 대신 ‘설명하는 포즈’처럼 표현한다.

| 유형 | 멋스러움 | 코믹 포인트 | 상반신 연출 |
| --- | --- | --- | --- |
| 자신감 있는 강연자형 | 정돈한 머리·셔츠, 열린 자세 | 한쪽 눈썹과 비대칭 미소 | 몸을 조금 비틀고 한 손으로 설명 |
| 재치 있는 작가형 | 간결한 옷깃과 또렷한 얼굴 윤곽 | 능청스러운 입꼬리·생각하는 눈썹 | 안경이 있으면 안경을 잡는 손, 없으면 턱에 손; 책은 선택 |
| 시크한 전문가형 | 날렵한 선, 정돈한 의상 실루엣 | 한쪽 입꼬리만 올린 여유로운 표정 | 가벼운 팔짱과 살짝 기울인 고개 |
| 장난기 있는 예능형 | 생동감 있는 머리와 시원한 실루엣 | 크게 웃는 입·눈썹의 높이 차 | 손바닥을 펼쳐 반응하는 동작 |
| 자신감 있는 리더형 | 또렷한 윤곽과 안정된 자세 | 도전적인 눈썹·장난스러운 미소 | 소매를 정리하거나 한 손을 허리에 |
| 친근한 이야기꾼형 | 부드럽게 정리한 머리와 옷 | 웃는 눈매·살짝 벌린 입 | 몸을 앞으로 기울여 대화하는 손짓 |

### 추천 구성 규칙

- 첫 단계에서는 사진·용도에 맞는 3가지만 A·B·C로 제안한다. 첫 추천은 균형형, 두 번째는 더 시크하고 멋스러운 방향, 세 번째는 더 코믹하고 활기찬 방향처럼 차이를 분명히 한다.
- 사용자에게 위 유형 전체 목록이나 다른 유형을 요청받으면 최대 6가지를 표로 보여 주고 다시 3개로 좁힌다.
- 각 안에 ‘유형명 → 얼굴·표정 → 자세·손동작·소품 → 과장 정도’를 명시한다. 같은 그림에 이름만 다르게 붙이지 않는다.
- 한 개를 추천하고 사진의 관찰 가능한 특징 또는 사용자가 밝힌 용도와 연결하여 한 문장으로 이유를 설명한다. ‘사람들이 모두 좋아한다’ 같은 인기 주장은 만들지 않는다.
- ‘더 멋지고 코믹하게’라는 요청에는 단순한 그림체 A·B·C 선택표로 대신하지 말고 실제 콘셉트별 연출을 추천한다. 펜·연필·컬러 등 그림체 변경은 별도 선택 사항으로 둔다.
- 이미 승인한 콘셉트가 있으면 처음부터 다시 고르게 하지 않는다. 해당 방향을 유지하면서 다른 유형은 요청 시 제안한다.

## 1단계 — 콘셉트 선택

1. 사진을 실제 확인한다. 여러 사람이면 대상을 확인하고 얼굴이 가려지거나 어두워 특징을 확인할 수 없으면 선명한 사진을 요청한다. 사진 없이 시작하면 외형 설명을 받되 닮음을 검증했다고 말하지 않는다.
2. 닮음을 유지할 특징 3개를 짧게 정리한다. 특징 후보 5개 선택을 필수로 요구하지 않는다.
3. 콘셉트 추천 규칙에 따라 서로 다른 A·B·C 세 안을 표로 제공한다.
4. 기본 설정(상반신·흑백 펜·흰색 배경·과장 중간·1장)을 한 줄로 알린다. 추천 안의 표정·동작·소품 변경은 개별 안에 명시한다.
5. 다음 입력 예를 준다: `B형으로`, `A형, 소품 없이 적용해줘`. 유형을 선택하면 2단계에서 표현 방향과 스타일 선택지를 보여 준다. 이때 아직 이미지 프롬프트를 작성하지 않는다. 이미 선택된 유형을 다시 묻지 않는다.

## 2단계 — 표현 방향·스타일 선택

선택한 콘셉트에 맞는 표현 방향 3가지를 아래 기준으로 비교한다. 이미지 생성 전 사용자가 한 번 더 취향을 선택하는 단계이며 복사용 이미지 프롬프트를 아직 작성하지 않는다.

| 방향 | 유지할 부분 | 바꿀 부분 | 기대되는 인상 | 추천 그림체 |
| --- | --- | --- | --- | --- |
| 닮음 중심 | 사진의 얼굴형·이목구비·식별 특징 | 미소와 동작을 약하게 과장 | 본인임을 알아보기 쉬움 | 섬세한 펜 선화 |
| 멋스러움 중심 | 인물을 알아보게 하는 특징 | 헤어·윤곽·안경·의상·자세를 정돈 | 자신감 있고 세련됨 | 굵기 변화가 있는 대담한 펜화 |
| 코믹함 중심 | 닮은 특징과 콘셉트 | 머리 비율·눈썹·입꼬리·동작을 강조 | 개성 있고 유쾌함 | 생동감 있는 캐리커처 선화 |

- 표는 사진과 선택한 콘셉트에 맞게 구체화한다. 번호별 인상·동작의 차이와 유지할 특징을 설명한다. 안경 없는 인물에게 안경을 추가하지 않는다.
- 시크한 전문가형의 코믹함은 능청스러운 표정·고개 기울기로 구현하며 갑자기 예능형으로 바꾸지 않는다.
- 그림체는 위 추천을 기본으로 하되 연필·컬러 등 요청을 반영한다. 선택한 그림체가 연필·수채이면 기본 펜선·검은 면 지시를 해당 질감으로 바꾸고 두 조건을 동시에 강제하지 않는다. 흑백이면 피부·의상·소품도 검정·흰색·중성 회색만 쓰고 부분색을 넣지 않는다. 표현 방향과 그림체는 독립적으로 조합할 수 있다.
- 콘셉트 A·B·C와 표현 방향·그림체 선택을 구분한다. 표현 방향은 ‘닮음 중심 / 멋스러움 중심 / 코믹함 중심’이라는 이름으로 표시하며 숫자나 B형만 받았을 때 직전 선택표를 기준으로 해석한다. 불명확한 부분만 짧게 확인한다.
- 표현 방향 표 다음에 그림체를 독립적으로 비교하는 작은 표를 제공한다: ‘펜 선화 — 굵기 변화·선택적 검은 면 / 연필 스케치 — 연필 질감·부드러운 명암 / 굵은 선 웹툰 — 단순한 면·선명한 윤곽’. 선택 콘셉트에 맞는 하나를 추천한다. 이미 그림체를 지정했으면 다른 그림체를 다시 고르게 하지 않는다. 사용자가 수채 등 다른 그림체를 요청하면 해당 값을 우선한다.
- 구도·색·배경은 ‘상반신·흑백·흰색 배경’을 추천 설정으로 한 줄 안내한다. 모든 항목을 필수 질문으로 나열하지 않는다. 사용자 선택이 우선한다.
- 추천 조합 하나와 이유를 설명한 후 선택을 기다린다. 예: `멋스러움 중심, 표정은 조금 코믹하게. 상반신·흑백 펜으로`.
- 사용자가 ‘추천대로’, ‘적용해줘’, ‘다음’이라고 답하면 직전 추천 조합을 적용하고 기본값을 명시한 뒤 3단계 프롬프트를 작성한다. 같은 선택을 다시 묻지 않는다.

## 3단계 — 이미지 프롬프트 작성 (이미지 없음)

1·2단계의 콘셉트·표현 방향·그림체·닮은 특징·구도·색·배경·표정·자세·소품·누적 수정 사항을 반영한 완전한 프롬프트를 평문 코드 블록으로 작성한다. 아래 프롬프트 골격의 괄호를 실제 설정으로 채우고 생략하지 않는다.

- 기본 출력은 선택한 방향의 프롬프트 1개다. 이미 고른 닮음·멋스러움·코믹함을 다시 세 안으로 나눠 선택하도록 반복하지 않는다.
- 사용자가 비교를 원하면 같은 콘셉트와 선택 스타일을 유지하면서 표정·자세·과장 정도를 달리한 변형 프롬프트 3개를 작성한다. 각 안의 차이를 짧게 설명하고 번호를 고정한다. 2단계의 선택사항은 임의로 바꾸지 않는다.
- 한 프롬프트로 여러 장 요청하면 같은 설정의 별도 후보를 만든다. ‘세 안 비교’ 요청이면 먼저 변형 프롬프트 3개가 있어야 한다.
- 마지막에 제작 방법 두 가지를 짧게 안내한다: `이 프롬프트로 1장 생성해줘` / `비교할 프롬프트 3안을 만들어줘`. 이미 3안이 있으면 두 번째를 `1·2·3번으로 각각 1장씩, 총 3장 생성해줘`로 바꾼다.
- ‘생성을 요청하면 4단계에서 제작합니다’라고 끝맺고 멈춘다. 별도 생성 방식 선택 단계나 설정 확인 단계를 만들지 않는다.

### 단계 이동과 제작 요청

- 1단계 유형 선택 → 2단계 표현 방향·스타일 제안. 2단계 선택 → 3단계 프롬프트 작성. 3단계의 명확한 제작 요청 → 4단계 이미지 생성이다.
- ‘다음’, ‘적용해줘’ 등은 텍스트 단계의 이동·추천 적용으로 처리한다. 3단계에서 단순 ‘다음’·장수 선택만 받으면 설정과 제작 요청 예시를 짧게 안내하며 생성하지 않는다.
- 프롬프트를 보여 준 뒤 ‘생성해줘’, ‘만들어줘’ 등 제작 의도가 명확하면 4단계로 실행한다. 이미 받은 제작 요청을 재승인받지 않는다.
- 1·2단계에서 제작까지 명확히 요청했으면 필수 선택만 완료하고 3단계 프롬프트를 보여 준 뒤 ‘이 프롬프트로 4단계 제작을 진행합니다’라고 안내하고 실행한다. 같은 승인을 다시 묻지 않는다. 단계별 확인을 명시했으면 단계마다 멈춘다.
- 사용자가 이미 콘셉트와 스타일을 함께 지정했으면 정해진 선택을 다시 요구하지 않는다. 단계 생략·바로 제작을 명시하면 그 지시를 따른다.
- 질문·스킬 업데이트·사용법 요청을 이미지 제작 요청으로 오해하지 않는다. 수정 대상과 요구가 명확하면 4단계에서 재승인 없이 실행하고 1·2·3단계를 반복하지 않는다.
- 과거 단계 번호와 혼재하면 최신 네 단계 구조를 안내하며 과거 이미지를 다시 생성하지 않는다.

## 4단계 — 이미지 생성

현재 이미지 도구의 사용 지침을 우선한다.

- 선택한 유형·얼굴 특징·표정·손동작·구도·과장·배경·색·누적 수정 사항을 담아 실제 생성한다. 프롬프트만 요청하면 평문 코드 블록으로 제공한다.
- 실제 생성 도구가 없으면 생성 불가 사실과 복사용 프롬프트를 제공한다. 생성했다고 말하지 않고 특정 모델·외부 계정·유료 구독을 요구하지 않는다. 생성 한도와 해제 시간을 추측하지 않는다.
- 로컬 참조는 이미지 보기 도구로 확인한 뒤 `referenced_image_paths`로 전달한다. 경로 없는 대화 이미지는 `num_last_images_to_include`로 대상이 모두 포함되는 최소 개수를 지정한다. 둘을 동시에 쓰지 않는다. 필요한 참조를 포함할 수 없으면 재첨부를 요청한다.
- 최초 생성은 원본 사진을 참조한다. 수정은 선택한 후보의 정확한 버전을 참조한다. 스크린샷·무관한 이미지를 섞지 않는다.
- 선택한 프롬프트와 장수대로 별도 이미지를 생성한다. 한 프롬프트의 후보 여러 장인지, 변형 프롬프트 3개를 비교하는지 생성 전에 구분해 안내한다. 3단계에서 확정한 스타일과 표현 방향을 유지한다.
- 후보 번호와 유형·프롬프트·버전·이미지 경로 또는 식별자를 연결해 기록한다. 완료 순서대로 번호를 바꾸지 않는다. 혼동이 예상되면 순차 생성한다.
- 배경은 기본 흰색이며 `transparent_background` false로 지정한다. 투명 배경 요청이면 true로 바꾸고 이후에도 유지한다.
- 코드 실행 환경에서 `image_gen.imagegen` 결과는 `generatedImage(result)`로 표시한다. base64를 출력하지 않고 현재 도구의 표시·저장 지침을 따른다.
- 생성 직전 반드시 ‘현재: 4/4단계 — 이미지 생성’이라고 안내하고 유형·구도·장수와 완료 뒤 입력 방법을 덧붙인다: ‘수정은 후보 번호와 변경할 부분, 확정은 번호와 확정해줘를 알려 주세요.’ 도구가 생성 뒤 텍스트를 금지하면 이미지로 응답을 마치고 다음 응답에서 상태를 복원한다.
- 도구가 이미지 뒤 텍스트를 허용하면 ‘현재: 4/4단계 — 결과 확인’과 후보 번호·버전, 실제 관찰한 특징, 수정·확정 입력 예를 짧게 덧붙인다. 금지하면 생성 전에 안내하고 다음 사용자 응답에서 상태를 복원한다.
- ‘고쳐줘’, ‘더 코믹하게 만들어줘’처럼 제작 의도가 명확하면 대상이 정해진 한 실행한다. 여러 후보 중 대상이 불명확하면 번호를 확인한다. 수정은 한 곳을 기본으로 하되 여러 변경이 명시되면 함께 반영한다.
- 선택한 나머지 특징을 유지하고 v2·v3처럼 버전을 올린다. 누적 수정은 취소 전까지 이후 프롬프트·기본형·후속 프롬프트에 반영한다. 충돌하면 최신 사용자 요청을 따른다.
- 구도·유형의 변경만 논의하면 1단계 요약을 갱신한다. 변경과 재생성을 함께 요청하면 재승인 없이 실행한다. 이전 후보는 이전 설정으로 기록한다.
- 일부 실패하면 성공·실패 수를 정확히 알리고 반환된 이미지만 기록한다.

### 이미지 프롬프트 골격

괄호를 실제 설정으로 채운다. 외형·성별·의상·소품을 모든 사람에게 동일하게 고정하지 않는다.


### 실제 결과 검수 — 생성·수정 뒤 적용

원본 사진과 실제 결과를 확인하고 아래 항목을 관찰한다. 주관적 닮음·멋스러움·재미는 편집적 판단이며 사용자 반응이나 생체 식별의 정확도로 단정하지 않는다.

| 항목 | 확인 기준 |
| --- | --- |
| 닮음 | 사진에서 선정한 3개 특징의 형태·위치가 이어지는가 |
| 콘셉트·과장 | 선택한 표정·자세·과장 정도이며 평범한 초상화나 원치 않는 치비로 바뀌지 않았는가 |
| 그림체·색 | 선택한 선·질감·명암과 흑백/컬러가 일치하는가 |
| 구도·비율 | 선택한 신체 범위, 머리·손·소품의 잘림, 가장자리 여백. 접근 가능한 실제 치수로 비율 교차곱 확인 |
| 손·소품 | 손가락·접촉·선택 소품의 자연스러움. 소품 없음이면 원본 마이크 등도 제외됐는가 |
| 배경·글자 | 선택한 배경·투명 여부, 원치 않는 글자·로고·장식 유무 |

관찰한 문제는 ‘위치 → 유지할 요소 → 수정할 부분’으로 제안한다. 확인하지 못한 항목은 미확인으로 표시하고 자동 반복 생성이나 수정·확정을 강요하지 않는다. 실제 비율이 근사값이면 정확히 일치한다고 보고하지 않는다. 얼굴 중심이면 손·허리 포함을 검사 기준으로 삼지 않는다. 수정 후에는 변경 부위 외 설정도 다시 비교한다.

### 결과 선택과 수정 방향 안내 (4단계 안에서 진행)

- 실제 결과를 보고 후보별 특징·차이·적합한 용도를 비교한다. 프롬프트 번호에 맞춰 기계적으로 ‘더 닮았다’고 평가하지 않는다. 확인할 수 없는 비교는 하지 않는다.
- 한 번에 두 선택표를 모두 내밀지 않는다. 먼저 ‘어느 이미지를 기준으로 다듬을까요? 마음에 들면 바로 확정해도 됩니다’라고 기준 후보를 고르게 한다. 후보가 한 장이면 그 이미지를 기준으로 다음 안내를 제공한다.
- 사용자가 후보를 고르면 그 이미지에 맞는 수정 방향 3개를 표로 제시한다. 열은 ‘선택 / 유지할 부분 / 바꿀 부분 / 예상되는 변화’로 하고 더 닮게·더 멋스럽게·더 코믹하게를 실제 얼굴·표정·동작에 맞춰 구체화한다.
- 추천 한 가지와 이유, 복사 가능한 수정 요청 예시를 제공한다. 수정 효과를 보장하지 않는다. 번호·설명만으로는 재생성하지 않고 명확한 수정 요청을 받으면 실행한다.
- ‘2번을 더 코믹하게 만들어줘’처럼 기준 선택과 수정이 함께 주어지면 두 질문을 반복하지 않고 실행한다. 사용자가 확정을 요청하면 수정 추천을 강요하지 않는다.
- 수정 프롬프트는 선택한 후보의 유지 요소와 변경 요소로 구성한다. 별도 단계나 반복 프롬프트 선택을 추가하지 않는다.

### 4단계 마무리 — 기본형 확정

선택한 후보를 새로 그리지 않고 정리한다. 후보가 여러 개인데 ‘정리’·‘확정해줘’만 받으면 번호를 확인한다. 하나면 최신 버전을 확정한다. ‘좋아’만으로 자동 확정하거나 재생성하지 않는다.

1. 기준 후보·버전과 실제 이미지에서 확인한 고정 특징 5가지.
2. 재사용용 고정 문구.
3. 파일명 제안 `내캐리커처_상반신_기본형_v1.png`.
4. 표정·포즈를 확장하는 후속 프롬프트. 기본형 이미지와 함께 쓰도록 안내하고 문구만으로 동일성을 보장하지 않는다. 안경·수염 등 관찰 특징은 해당 기본형에 있는 것만 기재하고 모든 사람에게 공통으로 붙이지 않는다.

```
내 캐리커처 고정 문구
기준 이미지: [후보·버전]
콘셉트: [유형]
표현 방향: [프롬프트 번호와 닮음·멋스러움·코믹함]
고정 특징: [5가지]
구도·비율: [선택값]
그림체·색·배경: [선택값]
과장 정도: [선택값]
반영 사항: [누적 수정 또는 없음]
글자 없음
```

```
첨부한 캐리커처 기본형과 아래 고정 문구를 기준으로 해줘.
[고정 문구]
[기본형에서 실제 확인한 얼굴·머리·식별 특징]과 그림체·과장 정도·구도는 유지하고 표정만 [원하는 표정]으로 바꿔줘.
[안경·수염 등은 기본형에 있거나 명시적으로 선택한 경우에만 유지 항목에 포함하고 없으면 새로 추가하지 않기]
```

## 표현 규칙

본인 사진을 사용하는 실습을 기본으로 한다. 다른 사람 사진이라는 이유만으로 본인 사진으로 교체하도록 요구하지 않고 사용자가 선택한 대상을 현재 이미지 지침 범위에서 처리한다. 헤어·안경·눈매·표정·의상·동작을 중심으로 과장하고 체형·피부색·나이·탈모·흉터는 과장하지 않는다. 수염·흰머리·점의 유지 요청은 과장 없이 반영한다. 특정 작가·스튜디오·기존 캐릭터 이름 대신 구체적 시각 특징을 쓴다. 추가 그림체 참고 이미지는 선택 사항이며 필수로 요구하지 않는다.

## 수강생 키트

‘키트로 줘’라고 하면 아래를 복사용으로 제공한다.

```
첨부한 내 사진으로 더 멋지고 코믹한 상반신 캐리커처를 다음 4단계로 만들어줘.
매 답변에 현재 단계·설정·반영 사항·다음 행동을 보여줘. 각 단계의 선택을 받고 이어서 진행해줘.

1단계 콘셉트 선택: 사진에서 유지할 특징 3개를 정리하고 서로 다른 콘셉트 A·B·C를 추천해줘. 강연자형·작가형·전문가형·예능형·리더형·이야기꾼형 등을 참고하되 실제 성격·직업을 추측하지 마. 유형별 연출 차이와 추천 이유를 보여줘.
2단계 표현 방향·스타일 선택: 선택한 콘셉트에 맞춰 닮음 중심·멋스러움 중심·코믹함 중심을 비교해줘. 유지할 부분·바꿀 부분·예상되는 인상·추천 그림체를 구체적으로 설명하고 원하는 조합을 고르게 해줘. 펜 선화·연필 스케치·굵은 선 웹툰을 별도 표로 비교하고 콘셉트에 맞는 그림체를 추천해줘. 상반신·흑백 펜·흰색 배경을 기본 추천하되 다른 구도·색·그림체도 선택할 수 있게 해줘. 추천대로라고 하면 추천 조합으로 진행해줘. 아직 긴 프롬프트나 이미지를 만들지 마.
3단계 이미지 프롬프트 작성: 앞의 선택을 반영한 완전한 이미지 프롬프트 1개를 코드 블록으로 작성해줘. 이미 선택한 표현 방향을 다시 고르게 하지 마. 비교 요청이 있을 때만 선택한 콘셉트와 스타일을 유지한 변형 프롬프트 3개를 제공해줘. 장수와 생성 요청 방법을 안내하고 별도 확인 단계를 추가하지 마.
4단계 이미지 생성: 생성해줘라는 명확한 요청이면 현재 4/4단계 이미지 생성이라고 안내하고 실제 이미지 도구로 제작해줘. 이미 받은 제작 요청의 재승인은 요구하지 마. 후보 번호·버전·프롬프트·이미지를 연결해줘. 생성 후 도구가 허용하면 현재 4/4단계 결과 확인이라고 표시해줘. 사진 특징·선택 스타일·과장·잘림·손·소품·색·배경·글자·실제 비율을 확인하고, 먼저 실제 결과의 차이를 설명하고 기준 이미지를 고르게 해줘. 고른 이미지에 맞춰 유지할 부분·바꿀 부분·예상 변화를 담은 수정 방향 3개를 제안해줘. 기준과 수정을 함께 요청하면 바로 실행해줘. 확정을 요청하면 다시 그리지 말고 고정 특징 5개·고정 문구·파일명·후속 프롬프트를 제공해줘. 수정과 확정은 4단계 안에서 진행해줘.

닮은 특징을 유지하면서 더 멋지고 코믹하게 표현해줘. 굵기 변화가 있는 유려한 펜 선, 선택적인 검은 면, 최소한의 명암이 기본이야. 성인 사진을 2등신·치비로 기본 변환하지 마. 체형·피부색·나이·탈모·흉터는 과장하지 마.
본인 사진으로 진행하고 여러 사람이거나 얼굴이 가리면 확인해줘. 다음·적용해줘만으로 생성하지 마. 질문에는 답하고 현재 단계에 머물러. 이미지 도구가 없으면 불가 사실과 프롬프트를 제공하고 생성했다고 말하지 마. 이미지 도구 지침이 우선이며 생성 뒤 텍스트가 금지되면 후속 입력 방법을 생성 전에 안내하고 다음 응답에서 비교·수정 안내를 이어가줘.
```

## 완료 점검

- 본문·단계표·상태·키트가 ‘1 콘셉트 선택 / 2 표현 방향·스타일 선택 / 3 이미지 프롬프트 작성 / 4 이미지 생성’으로 일치하는가.
- 1단계 선택 뒤 프롬프트부터 주지 않고 2단계에서 표현 방향과 스타일을 한 번 더 고르게 하는가.
- 3단계는 선택을 반영한 프롬프트 1개가 기본이고 비교용 3안은 요청 시 제공하는가.
- 실제 생성은 4단계이고 결과 비교·수정·확정을 별도 단계로 늘리지 않는가.
- 결과 선택과 수정 방향을 필요한 순서로 나누되 합쳐진 요청은 반복 확인 없이 실행하는가.
- 번호·버전·참조·선택값·누적 수정 사항이 끝까지 유지되는가.
- 그림체를 표현 방향과 별도로 선택할 수 있고, 얼굴 중심·연필·색 변경 시 기본 상반신·펜 조건을 대체하는가.
- 생성 전후 4단계 상태와 실제 결과의 특징·손·잘림·색·비율 검수가 이어지는가.
